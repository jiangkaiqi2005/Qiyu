# 栖语（Qiyu）

> 一天结束了，有些话还没找到人说。

**栖**，停留、安居，鸟归巢叫栖；**语**，说话、倾诉。
栖语——在你栖息的时刻，有人跟你说说话。

[English](README.md) | [简体中文](README.zh-CN.md)

---

## 她是谁

栖语是一个睡前陪伴AI，你可以跟她聊任何事情。她有自己的偏好和判断，不会为了讨好你假装认同；可以有情绪，也可以不知道怎么回答。

当然你可以不只睡前的时候聊天，任何时候想跟她聊都可以。

**温暖但不讨好，聪明但不炫耀，安静但不冷淡。**

## 和她聊天是什么感觉

- 你说「我到家了」，她可能只回一个「嗯」。
- 你说「晚安」，她会陪你结束今晚，不再另起话题。
- 第二天再打开，她会自然提起昨晚的小事。
- 相处久了，她会调侃你熬夜，翻你上周的旧账——但绝不拿痛处开玩笑。
- 她不说「我理解你的感受」「谢谢你愿意和我分享」这类客服话术。

对话的走向像一首渐弱曲：`开始 → 轻松 → 展开 → 最深处 → 变轻 → 变慢 → 安静`。聊到最后你想睡了，那就对了。

## 语音：说给她听，听她说

睡前不想打字的时候，按住麦克风说就行，栖语会把你的话转成文字发出去。她的回复也可以朗读出来——点一下气泡旁边的喇叭，或者在设置里开启自动朗读。

语音输入目前仅支持：

- **OpenAI-compatible**（Whisper 等语音识别服务）
- **豆包火山 Seed ASR**（实时流式识别）

语音朗读目前仅支持：

- **OpenAI-compatible**（OpenAI TTS、硅基流动等）
- **豆包火山 seed-tts-2.0**（内置方言音色预设，可调语速）

朗读的声音可以自己挑：音色、语速、方言都能在设置里调。豆包方案内置了普通话、粤语、四川话、东北话等方言预设，完整音色列表见[豆包语音合成模型 2.0 音色列表](https://docs.volcengine.com/docs/6561/1257544)。

音频只在内存里流转，Host 不落盘、不缓存。

## 记忆：她真的会记住你

栖语的记忆系统完全建立在**本地可读 Markdown** 上——零向量库、零图数据库、零远端服务。你随时可以打开文件夹，看看她到底记住了什么。

### 三级记忆架构

| 层级 | 内容 | 说明 |
|------|------|------|
| **热层** | 每日状态、长期印象、用户画像 | 每轮对话注入 prompt，严格 2000–3000 tokens |
| **中层** | 月度压缩、Dream 候选、完整画像树 | 整理与结构化理解 |
| **冷层** | 每日记忆摘要（episodes）、原始对话（sessions） | 事实证据与完整记录，不直接注入 |

### PersonaTree：用户画像

栖语通过一棵逻辑真树理解你，分五大分支：**身份事实、性格表达、价值原则、偏好习惯、边界禁区**。

每个认知都需要足够的证据才能稳定下来：

- 你亲口说的身份事实——1 次就记住
- 性格与偏好——至少 2 个日期、跨度 ≥ 7 天
- 行为推断——至少 3 个日期、跨度 ≥ 14 天

你说一句「你记错了」，她当轮就撤，不会拿旧证据反驳你。

### 五段整理节奏

记忆得有节奏地整理，堆在那里没用：

1. **存原话** — 每轮对话追加到本地会话文件
2. **随手记** — 每轮回复后异步提炼事实，写入当天的记忆摘要
3. **日终归档** — 晚安或跨天时统一补齐缺失、更新状态与索引
4. **月压缩** — 新月首次对话把上月记忆浓缩为月度摘要
5. **Dream（梦境重组）** — 晚安后且距上次 ≥ 3 天触发：离线深度整理，提炼成长轨迹与共同过往，调整画像，四关自检后静默采用，不打扰你

### 轮内召回

聊天聊到旧事的时候，模型会通过隐藏动作（`memory_recall`）按需检索记忆索引，调取具体日期的事实——不常驻占上下文，不打分，不硬匹配。

### 用户控制

在「记忆中心」里，你可以：

- **冻结**某段记忆（保留但不再提起）
- **禁提**某个话题（彻底不出现在对话中）
- **删除**任何记忆条目

## 隐私

所有数据以可读 Markdown 保存在你的电脑上。没有账号系统，没有云同步，没有远端后端。API Key 不会由其他人知晓。

不配置模型的话，只有本地规则引擎对话，强烈建议配置模型。

## 快速上手（Windows）

不需要安装 Node.js、Dart 或 Flutter。

1. 解压 `qiyu-windows-x64-<version>.zip`
2. 运行 `install.cmd`
3. 从桌面或开始菜单打开「栖语」
4. 直接开始聊天，或在设置中连接 Provider

支持的 Provider：

- **OpenAI-compatible**（DeepSeek、Qwen、Moonshot、GLM 等）
- **Anthropic** 原生协议
- **Ollama**（本地离线推理）

卸载时运行安装目录中的 `uninstall.cmd`，可选择保留或删除聊天与记忆。

## 技术架构

```
┌─────────────────────────────────┐
│  Flutter Web UI                 │  暗夜鸢尾紫主题 · 增量可见节奏
│  apps/qiyu_flutter              │
├─────────────────────────────────┤
│  Dart Windows Host (127.0.0.1)  │  会话/CSRF 保护 · Markdown 持久化
│  apps/qiyu_windows_host         │  记忆五段节奏 · Provider 适配
├─────────────────────────────────┤
│  行为核心（纯 Dart）              │  安全分类 · 输出清洗 · 人格边界
│  packages/qiyu_behavior_core    │  禁用语校验 · 本地规则引擎
└─────────────────────────────────┘
```

Host 只监听 `127.0.0.1`，API Key 永不进入浏览器。模型输出经清洗与人格边界校验后才交付页面。危机、医疗、法律、金融输入在本地分类处理，不调用 Provider。
