# 栖语（Qiyu）

> 一天结束了，有些话还没找到人说。

**栖**，停留、安居，鸟归巢叫栖；**语**，说话、倾诉。
栖语——在你栖息的时刻，有人跟你说说话。

你可以跟他聊任何事情，比如今天你想总结干了什么，或是倾诉一些只能和自己说的事情。等等。

## 她是谁

栖语是一个睡前陪伴AI，你可以跟她聊任何事情。她有自己的偏好和判断，不会为了讨好你假装认同；可以有情绪，也可以不知道怎么回答。

当然你可以不只睡前的时候聊天，任何时候想跟她聊都可以。

**温暖但不讨好，聪明但不炫耀，安静但不冷淡。**

## 和她聊天是什么感觉

- 你说 “我到家了”，她可能只回一个“嗯”。
- 你说“晚安”，她会陪你结束今晚，不再另起话题。
- 第二天再打开，她会自然提起昨晚的小事。
- 相处久了，她会调侃你熬夜，翻你上周的旧账——但绝不拿痛处开玩笑。
- 她不说“我理解你的感受” ”谢谢你愿意和我分享”这类客服话术。

## 语音：说给她听，听她说

睡前不想打字的时候，直接说就行。

- 在电脑上：点输入框旁的麦克风，开始说话；说完再点一下（按钮会变成「说完，转成文字」），话就转成文字发出去。
- 在手机上：点一下麦克风进入语音模式，按住按钮说话，松手就发送。要是不想发了，往上一滑就是取消。

她的回复也可以朗读出来——点一下气泡旁边的喇叭，或者在设置里开启自动朗读。

语音朗读非常有意思，你可以自由调节音色，语速，方言等。当然你需要阅读语音朗读模型的官方文档，根据模型支持的功能进行修改。

建议打开语音朗读功能。

语音输入目前支持：

- **OpenAI-compatible**（Whisper 等语音识别服务）
- **豆包火山 Seed ASR**（实时流式识别）
- **千问语音识别**（阿里云百炼 DashScope，默认模型 `qwen3-asr-flash`，还目前还不支持新的`qwen-audio-3.0-asr-flash-filetrans`）
- **自定义服务**（填入任意兼容端点，自定义鉴权与响应解析）

语音朗读目前支持：

- **OpenAI-compatible**（OpenAI TTS、硅基流动等）
- **豆包火山 seed-tts-2.0**（内置方言音色预设，可调语速）
- **千问语音合成**（阿里云百炼 DashScope，默认模型 `qwen3-tts-flash`，音色自由填写，目前还不支持新的`qwen-audio-3.1-tts-next`）
- **自定义服务**（填入任意兼容端点，支持原始字节、JSON 字段或逐行 JSON 三种响应形态）

建朗读的声音可以自己挑：音色、语速、方言都能在设置里调。豆包方案内置了普通话、粤语、四川话、东北话等方言预设，完整音色列表见[豆包语音合成模型 2.0 音色列表](https://docs.volcengine.com/docs/6561/1257544)。

音频只在内存里流转，Host 不落盘、不缓存。

## 记忆：她真的会记住你

栖语的记忆系统完全建立在**本地可读 Markdown** 上——零向量库、零图数据库、零远端服务。你随时可以打开文件夹，看看她到底记住了什么。

### 三级记忆架构

| 层级 | 内容 | 说明 |
|------|------|------|
| **热层** | 每日状态、长期印象、用户画像 | 每轮对话注入 prompt，严格 2000–3000 tokens |
| **中层** | 月度压缩、Dream 候选、完整画像树 | 整理与结构化理解 |
| **冷层** | 每日记忆摘要（episodes）、原始对话（sessions） | 事实证据与完整记录，不直接注入 |

### PersonaTree：用户画像

栖语通过一棵逻辑真树理解你，分五大分支：**身份事实、性格表达、价值原则、偏好习惯、边界禁区**。

每个认知都需要足够的证据才能稳定下来：

- 你亲口说的身份事实——1 次就记住
- 性格与偏好——至少 2 个日期、跨度 ≥ 7 天
- 行为推断——至少 3 个日期、跨度 ≥ 14 天

你说：“你记错了”，她当轮就撤掉错误记忆，不会拿旧证据反驳你。

### 五段整理节奏

记忆有节奏地整理：

1. **存原话** — 每轮对话追加到本地会话文件
2. **随手记** — 每轮回复后异步提炼事实，写入当天的记忆摘要
3. **日终归档** — 晚安或跨天时统一补齐缺失、更新状态与索引
4. **月压缩** — 新月首次对话把上月记忆浓缩为月度摘要
5. **Dream（梦境重组）** — 晚安后且距上次 ≥ 3 天触发：深度整理，提炼成长轨迹与共同过往，调整画像，四关自检后静默采用，不会打扰你

### 轮内召回

聊天聊到旧事的时候，模型会通过隐藏动作（`memory_recall`）按需检索记忆索引，调取具体日期的事实。不会常驻占上下文，不打分，不硬匹配。

### 用户控制

在 “记忆中心” 里，你可以：

- **冻结**某段记忆（保留但不再提起）
- **禁提**某个话题（彻底不出现在对话中）
- **删除**任何记忆条目

## 隐私

所有数据以可读 Markdown 保存在你自己的设备上。没有账号系统，没有云同步，没有远端后端。API Key 不会由其他人知晓。

不配置模型的话，只有本地规则引擎对话，强烈建议配置模型。

## 快速上手（Windows）

不需要安装任何开发环境，解压就能用。

1. 解压 `qiyu-windows-x64-<版本>.zip`
2. 运行里面的 `install.cmd`
3. 从桌面或开始菜单打开「栖语」
4. 直接开始聊天，或在设置里连接模型

第一次运行时，如果 Windows 弹出「Windows 已保护你的电脑」，这是未签名安装包的常规提示：点「更多信息」，再点「仍要运行」，就能继续安装。

模型服务的 Key 去哪申请：

- **火山方舟（豆包）**：在火山引擎官网注册，进入「火山方舟」控制台创建 API Key，回栖语「设置 → 模型连接」选「火山方舟」填入。
- **其他常见模型**（DeepSeek、Qwen、Moonshot、GLM 等）：到对应服务商官网的控制台申请 API Key，同样在「设置 → 模型连接」里填。
- **Ollama**：跑在你自己的电脑上，本地推理，不需要 Key。

卸载的方法在下面「数据存在哪，怎么备份」一节。

## 安装（安卓）

安卓版把栖语整个装进手机。对话、记忆和设置都只存在这台手机上。

1. 在栖语的发布页（[GitHub Releases](https://github.com/jiangkaiqi2005/Qiyu/releases)）下载安装包。安装包按手机芯片架构拆成几个文件，文件名末尾标着对应架构：多数手机选 `arm64-v8a`；少数较旧的手机选 `armeabi-v7a`；`x86_64` 一般只有电脑上的模拟器才用。装错架构会装不上，换对应文件再试即可。
2. 把安装包传到手机点开（或用手机直接下载），系统提示 “未知来源” 或询问是否允许安装时，选择允许。
3. 打开“栖语”，第一次见面她会问怎么称呼你。

## 数据存在哪，怎么备份

栖语没有云端，所有数据只有你手里这一份：

- **Windows**：对话与记忆在 `C:\Users\你的用户名\.qiyu` 文件夹里，是能直接打开看的 Markdown 文本；模型连接等设置也在同一个文件夹，是几个可读的小文件（比如 `provider.json`）。换电脑或重装前，把这个文件夹整个拷走，对话、记忆和设置就都带上了。
- **安卓**：全部数据都在栖语自己的应用空间里，其他应用读不到；具体位置可以在「设置 → 本地数据」里看到。

**备份**：在「设置 → 本地数据 → 备份与恢复」导出，得到一个 Markdown 文件，发给自己留存即可；换手机或重装之后，从同一入口导入，先预览差异再恢复。API Key 与模型凭据从不进入备份。

**卸载前必读**：对话与记忆没有别的副本——

- Windows 上运行安装目录里的 `uninstall.cmd`，它会问你要不要保留数据：保留，数据原样在原处；删除，全部清掉。
- 安卓上卸载应用、或在系统设置里清除应用数据，都会丢掉全部对话与记忆。动手前先导出备份。

## 联网搜索

聊到会变化的事情——今天几号、外面的天气、最近有什么新闻——栖语会按需联网搜一下，把查到的融进回答，不用你切出去查了再回来。

用这个能力需要在「设置 → 联网搜索」里填一个 AnySearch 的 API Key（在 AnySearch 官网申请），Key 只保存在本机。不填的话聊天照常，只是她不会去搜。

## 技术架构

```
┌─────────────────────────────────┐
│  Flutter Web UI                 │  暗夜鸢尾紫主题 · 增量可见节奏
│  apps/qiyu_flutter              │
├─────────────────────────────────┤
│  Dart Windows Host (127.0.0.1)  │  会话/CSRF 保护 · Markdown 持久化
│  apps/qiyu_windows_host         │  记忆五段节奏 · Provider 适配
├─────────────────────────────────┤
│  行为核心（纯 Dart）              │  安全分类 · 输出清洗 · 人格边界
│  packages/qiyu_behavior_core    │  禁用语校验 · 本地规则引擎
└─────────────────────────────────┘
```

Host 只监听 `127.0.0.1`，API Key 永不进入浏览器。模型输出经清洗与人格边界校验后才交付页面。危机、医疗、法律、金融等输入照常交给模型回应，模型未配置或没有回应时由本地兜底话术接住（危机输入给出 12356 心理援助热线）。

安卓版复用同一套界面与核心，把本机服务直接装进应用里，同样不需要任何云端。
