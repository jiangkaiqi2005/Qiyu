## 验收说明

- 当前 Windows `10.0.26200.0` 实机已完成隔离用户目录安装、启动、同目录覆盖升级、两种卸载策略，并在只保留系统目录的 `PATH` 下通过预检；但当前会话无管理员权限，无法启用 Windows Sandbox，因此独立干净 VM 子项保持未勾选，不以隔离目录冒充干净 VM。
- 浏览器启动失败由自动化测试覆盖；为避免破坏用户的系统关联，没有在实机人为制造该失败。系统重启边界按“安装器不写开机自启、用户再次启动后恢复”验收，实机执行了强制退出与重启留存，没有重启当前用户电脑。
- 无敏感值的结构化结果、复现脚本、完整门禁日志和包摘要位于 `.scratch/ticket25-release/`。
- 派发 prompt 引用的 Obsidian `T25-记忆中心UI接管.md` 是编号冲突，不是本票的打包 Resolution；本票以产品灵魂、`栖语启动.md`、Flutter Windows 产品 Spec 和本清单交叉核对，未发现实质设计冲突。
