# 25 — 产出 Windows 安装包与本机安全验收

**What to build:** 把完整产品打成可安装、升级和卸载的 Windows 候选版本，并验证它在离线、本机网络和凭据安全方面满足首发边界。

**Blocked by:** 21「完成损坏隔离与证据驱动恢复」、22「完成 Markdown 备份导入导出」、24「收口响应式、键盘与无障碍体验」

**Status:** ready-for-agent

- [ ] 安装包在干净的受支持 Windows 环境中完成安装、启动、升级和卸载，不要求用户安装 Node 或开发工具。
- [ ] Flutter Web 资源、Dart 宿主和必要许可证全部随包提供，断网时除用户主动调用远程 Provider 外均可运行。
- [ ] 安装与升级保留用户 Markdown 数据和 Windows 安全存储中的 Provider Key；卸载时明确询问是否保留数据。
- [ ] 网络验收证明宿主只监听环回地址，拒绝其他设备、异常 Host、异常 Origin、旧凭据和伪造修改请求。
- [ ] 包内不存在远程静态资源、测试密钥、开发后门、旧 Node 运行依赖或非首发平台产物。
- [ ] 单实例、浏览器启动失败、端口竞争、宿主意外退出和系统重启后的行为均有可理解结果。
- [ ] 完成安装冒烟、离线聊天、Provider 聊天、重启留存、备份恢复、安全检查和卸载数据策略的发布验收记录。
