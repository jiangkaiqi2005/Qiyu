# 07 — 提供跨重启的每日记录与历史浏览

**What to build:** 让用户能够按日期和会话浏览自己的本地聊天记录，并在刷新、跨日和重启之后准确恢复最近上下文。

**Blocked by:** 03「打通本地规则聊天与原始会话落盘」

**Status:** done

- [x] 历史页按本地日期列出会话，展示可辨认的时间、首条摘要和消息数量。
- [x] 用户可以打开任意会话阅读全文，并从最近会话继续聊天。
- [x] 日期变化后新消息进入新一天，旧会话不被覆盖或错误拼接。
- [x] 用户可以删除一段原始会话，并在明确确认后更新历史列表和当前会话状态。
- [x] 浏览历史不触发模型调用、记忆提炼或关系阶段变化。
- [x] 缺失、空白或无法解析的单个会话不会阻塞其他历史记录；异常项有可恢复提示。
- [x] 测试覆盖跨日、时区边界、重启恢复、删除和局部损坏场景，并验证全部数据仍只在本机。
