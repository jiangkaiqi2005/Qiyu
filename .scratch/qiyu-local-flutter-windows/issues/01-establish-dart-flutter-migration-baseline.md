# 01 — 建立并行 Dart/Flutter 迁移基线

**What to build:** 在现有产品仍可运行的前提下，建立纯 Dart 行为核心、Flutter Web 应用和 Windows 本机宿主的最小工程骨架，并准备跨实现共享的行为契约，为后续逐条迁移提供可验证的扩展阶段。

**Blocked by:** 无

**Status:** done

- [x] Dart、Flutter Web 和 Windows 本机宿主都能在受支持的 Windows 开发环境中完成构建与启动前检查。
- [x] 纯 Dart 行为核心不依赖 Flutter、浏览器 API、Node 或具体存储实现。
- [x] 定义聊天请求、聊天结果、状态快照和错误结果的稳定契约，后续切片无需绕过该契约。
- [x] 从现有实现提取一小组跨语言契约样例，至少覆盖普通回复、晚安收束、安全降级和违禁话术降级。
- [x] Dart 侧契约测试通过，现有 JavaScript 测试与行为评估仍保持全绿。
- [x] 新工程不引入数据库、云服务、账号系统、远程静态托管或移动端专用实现。
- [x] 选用的第三方包有活跃维护、明确许可证和 Windows/Flutter Web 支持；记录选择理由，避免自研已有成熟实现。
