# 02 — 启动 Windows 本机 Web 外壳

**What to build:** 让用户运行 Windows 本机程序后，自动得到一个只在本机可访问的 Flutter Web 页面，并建立后续本机 API 使用的安全启动会话。

**Blocked by:** 01「建立并行 Dart/Flutter 迁移基线」

**Status:** ready-for-agent

- [ ] 启动程序只绑定环回地址，并使用可用的随机端口提供打包在应用内的 Web 资源。
- [ ] 程序启动后自动打开默认浏览器；浏览器打开失败时，用户仍能看到并复制本机地址。
- [ ] 第二次启动不会创建相互竞争的宿主实例，而是复用或聚焦已有实例。
- [ ] 每次宿主启动产生新的页面访问凭据，旧标签页或旧凭据在宿主重启后失效。
- [ ] 本机 API 拒绝非预期 Host、Origin、会话凭据和修改请求，页面静态资源不依赖远程 CDN。
- [ ] 关闭宿主后端口被释放，页面明确显示本机程序已停止，而不是无限加载。
- [ ] 自动化测试覆盖环回绑定、随机端口、单实例、凭据失效和来源校验；人工演示可从可执行程序进入空应用页面。
