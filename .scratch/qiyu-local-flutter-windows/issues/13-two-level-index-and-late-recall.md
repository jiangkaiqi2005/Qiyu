# 13 — 实现两级索引与“晚一拍想起”

**What to build:** 用只负责定位、不充当事实真相的月级与全局索引支持旧事召回，并允许栖语在首次没有想起时诚实回应、后台查找、下一轮自然补充。

**Blocked by:** 09「实现伪 Agent 白名单动作与增量 Episode」、10「完成日终归档与近日状态重建」

**Status:** done

- [x] 月级索引从当天 Episode 生成定位信息，全局索引只聚合月份和高层主题入口。
- [x] 回答旧事前必须读取索引指向的原始证据，索引摘要本身不能作为最终事实来源。
- [x] 当前热层未命中时，栖语可以明确表示一时没想起，不编造相似经历。
- [x] 后台召回找到可信证据后写入短期 memory context，并在下一轮语境合适时自然补充。
- [x] 多个相似候选、证据冲突或置信不足时不强行认定；诊断信息能说明未采用原因。
- [x] 索引缺失或损坏不影响普通聊天，并可以从原始 Episode 重建。
- [x] 测试覆盖命中、未命中、晚一拍补充、冲突、错误索引、重建和跨月定位。
