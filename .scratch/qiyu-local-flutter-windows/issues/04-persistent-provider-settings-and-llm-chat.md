# 04 — 打通持久 Provider 配置与真实模型回复

**What to build:** 让用户在本机页面配置受支持的模型 Provider，安全持久保存配置并完成一次真实模型聊天，同时保留无配置或调用失败时的本地可用性。

**Blocked by:** 03「打通本地规则聊天与原始会话落盘」

**Status:** ready-for-agent

- [ ] 设置页支持 OpenAI-compatible、Anthropic 和 Ollama 所需的最小配置字段，不暴露与首发无关的高级选项。
- [ ] API Key 通过成熟的 Windows 凭据安全方案保存；普通 Provider 配置持久保存，关闭标签页和重启程序后仍可使用。
- [ ] 页面只能判断 Key 是否已设置，任何读取、日志、错误或诊断响应都不能返回完整 Key。
- [ ] 用户可以测试当前配置，得到成功、鉴权失败、网络失败、模型不存在等可区分结果。
- [ ] 配置成功后，聊天能够调用所选 Provider，并把最终回复和来源写入同一原始会话。
- [ ] Provider 未配置或调用失败时自动回到本地规则回复，用户不丢失已发送消息。
- [ ] HTTP 客户端和凭据存储均通过接口注入以便测试；使用官方协议文档和成熟客户端能力，不自行发明 Provider 协议。
- [ ] 测试覆盖三类 Provider 的请求映射、配置重启留存、Key 不回传、真实回复路径和失败降级。
