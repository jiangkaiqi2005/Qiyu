# 23 — 收口设置、隐私与开发者诊断

**What to build:** 完成产品级设置、隐私控制和本机诊断体验，使普通用户能管理 Provider 与数据，开发者能定位降级和后台任务问题，但任何诊断都不泄密。

**Blocked by:** 04「打通持久 Provider 配置与真实模型回复」、05「固化安全门、输出清洗与本地降级」、18「让记忆控制贯穿聊天和整理管线」、22「完成 Markdown 备份导入导出」

**Status:** ready-for-agent

- [ ] 设置页完整管理 Provider、模型、本地数据位置和必要的体验选项，危险操作有明确影响与确认。
- [ ] 隐私页说明数据只在本机、何时调用用户选择的模型服务、哪些敏感信息永不提升为记忆。
- [ ] 用户可以进入备份、清除产品数据、记忆控制总览和 API Key 替换或移除流程。
- [ ] 开发者诊断显示最近请求来源、fallback reason、后台整理状态、Dream 资格和本地文件健康度。
- [ ] 实验室能力默认不打扰普通用户，并且不能修改生产数据或绕过安全与记忆控制。
- [ ] 所有日志和诊断导出统一脱敏；API Key、授权头、启动凭据和默认遮罩的敏感原文绝不出现。
- [ ] 测试覆盖设置持久化、Key 替换与移除、清除确认、诊断准确性、实验室隔离和敏感字段扫描。
