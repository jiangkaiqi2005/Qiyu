# 20 — 完成记忆编辑、控制与敏感查看

**What to build:** 在记忆中心提供经过确认的编辑、冻结、禁止提及、删除和敏感证据查看操作，使用户真正拥有本地记忆的控制权。

**Blocked by:** 18「让记忆控制贯穿聊天和整理管线」、19「提供四区只读记忆中心」

**Status:** ready-for-agent

- [ ] 用户可以修正可编辑的记忆文本；修正作为用户声明保存，不伪装成原始会话证据。
- [ ] 冻结、解除冻结和禁止提及操作立即反映在界面，并在下一轮聊天与后台整理中生效。
- [ ] 删除前展示准确影响范围，包括会被重建或清理的索引和派生理解，不使用含糊的全部删除表述。
- [ ] 查看敏感证据需要明确的临时揭示动作，离开页面或超时后重新遮罩，不写入日志或剪贴板。
- [ ] 编辑或控制后只重建必要的派生层，原始会话除用户明确删除外保持不变。
- [ ] 每次操作都有成功、部分失败和可恢复失败结果；失败时旧有效数据保持可用。
- [ ] 测试覆盖编辑来源、冻结、禁止、删除范围、敏感遮罩、最小重建、失败回滚和跨重启一致性。
