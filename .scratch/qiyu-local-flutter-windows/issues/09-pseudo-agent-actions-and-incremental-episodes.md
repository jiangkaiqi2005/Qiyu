# 09 — 实现伪 Agent 白名单动作与增量 Episode

**What to build:** 允许模型在回复之外提出少量受控的隐藏记忆动作，由本地运行时验证后更新当天 Episode 和 checkpoint，使栖语表现出连续性但不成为通用 Agent。

**Blocked by:** 06「实现流式回复与睡前呈现节奏」

**Status:** done

- [x] 隐藏动作只有明确白名单，不能访问网络、执行任意命令、修改任意文件或调用未授权工具。
- [x] 动作协议与用户可见文本严格分离，解析失败或未知动作只被忽略并记录诊断，不显示给用户。
- [x] 只有通过字段校验、证据校验和敏感信息过滤的动作才能进入记忆写入队列。
- [x] 当天对话按四到六轮或显著信号触发增量 Episode 更新，并保存可继续处理的 checkpoint。
- [x] 密码、Key、令牌、验证码、私钥和完整证件或银行卡信息不会被提升为记忆。
- [x] 同一动作重复提交具有幂等性；模型调用成功但记忆写入失败不影响当前回复落盘。
- [x] 测试覆盖合法动作、未知动作、越权动作、敏感信息、重复动作、写入失败和隐藏内容不泄漏。
