# 24 — 收口响应式、键盘与无障碍体验

**What to build:** 对完整 Windows Web 产品进行一次横向体验收口，使聊天、历史、记忆和设置在常见窗口尺寸、键盘操作和辅助技术下都可稳定使用。

**Blocked by:** 06「实现流式回复与睡前呈现节奏」、08「完成自然的首次见面与配置分流」、19「提供四区只读记忆中心」、20「完成记忆编辑、控制与敏感查看」、23「收口设置、隐私与开发者诊断」

**Status:** ready-for-agent

- [ ] 所有首发页面在小窗口、常见笔记本尺寸和宽桌面尺寸下无关键内容溢出、遮挡或不可达。
- [ ] 全部主要流程可仅使用键盘完成，焦点顺序、焦点可见性、对话框陷阱和返回行为一致。
- [ ] 交互控件具有准确语义、名称、状态和错误关联，屏幕阅读器能理解流式回复和状态变化。
- [ ] 颜色对比、字号缩放、触控目标和高对比模式达到成熟 Web 无障碍实践要求。
- [ ] 尊重减少动态效果设置；关闭动画后不影响流式文本、导航或完成反馈。
- [ ] 聊天滚动在新消息、流式增长、用户上翻和历史恢复时保持可预测，不强行抢回底部。
- [ ] 自动化无障碍检查、键盘集成测试和三档窗口截图回归通过，并完成人工屏幕阅读器抽查。
