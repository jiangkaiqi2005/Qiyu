# 03 — 打通本地规则聊天与原始会话落盘

**What to build:** 交付第一条完整聊天路径：用户在 Flutter 页面发送消息，经本机宿主进入纯 Dart 行为核心，收到本地规则回复，并把原始会话可靠保存为 Markdown。

**Blocked by:** 02「启动 Windows 本机 Web 外壳」

**Status:** done

- [x] 聊天页可以发送非空文本并展示用户消息和栖语的本地规则回复。
- [x] 未配置 Provider 时产品仍可完整聊天，并明确记录回复来源为本地降级而非报错。
- [x] 每轮用户消息和最终回复按顺序写入当天原始会话，采用不会留下半个有效文档的原子写入策略。
- [x] 刷新页面、关闭标签页或重启本机程序后，可以继续最近一次会话且不会重复消息。
- [x] 单会话容量和历史保留策略有明确上限；达到上限时按产品规则开启新段而不是静默丢失。
- [x] 存储目录初始化、Markdown 解析失败和写入失败都返回可理解的本地错误，不伪装为成功。
- [x] Repository、行为核心、本机 API 和 Flutter 聊天页均有对应测试，至少一条集成测试覆盖发送、落盘、重启、恢复全过程。
