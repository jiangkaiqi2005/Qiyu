# 11 — 打通 Open-loop 自然跟进生命周期

**What to build:** 让栖语能够记住真正未完的事情，在合适的后续对话中自然问起，并尊重完成、过期、遗忘和禁止提及。

**Blocked by:** 10「完成日终归档与近日状态重建」

**Status:** done

- [x] 日终候选只有满足明确未完性和后续价值时才提升为 Open-loop，不把普通闲聊都变成任务。
- [x] 每个 Open-loop 具有稳定标识、证据、状态、最早可跟进时间和过期规则。
- [x] 栖语只在当前语境自然、关系阶段允许且没有更重要安全事项时发起跟进。
- [x] 跟进后可以根据用户回复转为完成、继续等待、过期或遗忘，状态变化可追溯。
- [x] 用户要求不再提及时立即禁止该事项，后续整理和 Dream 不得重新激活。
- [x] 一次对话不会同时抛出多个待办式追问，晚安时不会发起新的跟进。
- [x] 测试覆盖创建、延迟、自然触发、完成、过期、禁止、跨重启和重复日终处理。
