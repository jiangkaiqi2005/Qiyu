# 22 — 完成 Markdown 备份导入导出

**What to build:** 让用户把完整本地数据导出为可理解、可携带的 Markdown 备份，并在版本校验、冲突预览和回滚保护下恢复。

**Blocked by:** 20「完成记忆编辑、控制与敏感查看」、21「完成损坏隔离与证据驱动恢复」

**Status:** done

- [x] 导出包含原始会话、派生记忆、用户控制和必要元数据，但不包含 API Key、宿主凭据、缓存或日志。
- [x] 备份具有版本、生成时间、完整性清单和清晰的人类可读说明，不依赖数据库工具才能检查。
- [x] 导入前验证结构、版本和完整性，并向用户展示新增、替换、冲突、跳过和不可恢复项目。
- [x] 默认不静默覆盖当前数据；用户确认后先创建可回滚快照，再执行原子导入。
- [x] 导入继续尊重本机现有的禁止提及和删除控制，冲突时采用更保守的隐私结果。
- [x] 不兼容或损坏备份被拒绝且不改变现有数据；成功导入后可重新打开历史、记忆和最近会话。
- [x] 测试覆盖完整往返、旧版本、损坏清单、冲突、取消、导入中断、回滚和 Key 不进入备份。
