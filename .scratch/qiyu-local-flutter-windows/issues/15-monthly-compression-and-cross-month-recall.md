# 15 — 完成月压缩与跨月召回

**What to build:** 在月份结束或首次进入新月时，把已经完成日终整理的内容压缩成可追溯月度摘要，并让旧月份仍能通过全局索引被准确召回。

**Blocked by:** 10「完成日终归档与近日状态重建」、13「实现两级索引与‘晚一拍想起’」

**Status:** done

- [x] 只压缩已经 finalized 的日期，未完成或损坏的日期被明确跳过并等待修复。
- [x] 月度摘要区分发生过的事情、仍未解决的线索、关系变化和不确定内容，不制造原文不存在的结论。
- [x] 每个摘要条目保留到日期或 Episode 的证据引用，能够继续定位到原始记录。
- [x] 进入新月、跨年或启动补做时流程幂等，同一月份不会重复生成相互冲突的摘要。
- [x] 全局索引能够定位跨月与跨年的相关月份，并继续遵守先索引后证据的召回规则。
- [x] 月压缩失败不阻塞聊天或原始会话保存，成功接纳前旧摘要保持可用。
- [x] 测试覆盖正常月结、缺失日期、跨年、重复执行、部分失败、证据追溯和跨月召回。
