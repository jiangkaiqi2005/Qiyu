# 08 — 完成自然的首次见面与配置分流

**What to build:** 为首次打开和再次回来的用户提供符合栖语气质的入口，使他们无需理解技术架构就能开始聊天或完成必要配置。

**Blocked by:** 04「打通持久 Provider 配置与真实模型回复」、07「提供跨重启的每日记录与历史浏览」

**Status:** ready-for-agent

- [ ] 全新用户看到简短、自然的首次见面流程，不使用客服式说明或冗长功能导览。
- [ ] 未配置 Provider 时可以选择先使用本地回复或进入设置，不把 Key 当作进入产品的强制门槛。
- [ ] 已配置 Provider 的新用户完成首次见面后直接进入聊天，不重复询问已保存配置。
- [ ] 回访用户跳过首次见面，并回到最近会话或清晰的首页入口。
- [ ] 首次见面完成状态持久留存；清除本地产品数据后可重新进入首次流程。
- [ ] 首页提供聊天、历史、记忆和设置的清晰入口，但不展示尚未完成或首发范围外的能力。
- [ ] Widget 和端到端测试覆盖全新、未配置、已配置、回访和清除数据五条路径。
