# 18 — 让记忆控制贯穿聊天和整理管线

**What to build:** 把用户的不要记、别再提、冻结和删除意图变成统一的本地控制规则，使其立即影响聊天、召回、索引、PersonaTree、Open-loop 和 Dream。

**Blocked by:** 11「打通 Open-loop 自然跟进生命周期」、12「打通关系阶段、温度与行为变化」、13「实现两级索引与'晚一拍想起'」、17「完成 Dream 根节点、Persona 与共同过往」

**Status:** done

- [x] 聊天中明确表达不要记时，本轮相关内容不进入新的记忆提升、索引或 PersonaTree。
- [x] 别再提创建可持久执行的禁止提及规则，后续回复、主动跟进和 Dream 都不能绕过。
