# 06 — 实现流式回复与睡前呈现节奏

**What to build:** 让模型回复以稳定、克制的流式体验呈现，同时保证中断、重试、晚安收束和本地降级都不会破坏会话一致性。

**Blocked by:** 05「固化安全门、输出清洗与本地降级」

**Status:** ready-for-agent

- [ ] 支持的 Provider 以统一事件模型向页面传递增量文本、完成、错误和降级结果。
- [ ] 页面只展示已通过安全边界的内容；若必须缓存到完整结果后检查，应使用自然的等待状态而不是泄露未验证文本。
- [ ] 用户可以停止正在生成的回复，停止后不会留下被当成完整回复的半成品记录。
- [ ] 网络中断、标签页刷新和宿主重启不会造成同一轮重复写入或重复展示。
- [ ] 回复呈现遵循少回应、短段落和睡前低刺激节奏；用户说晚安时只收束，不开启新话题。
- [ ] 本地规则回复和模型降级结果使用与流式回复一致的完成事件与落盘语义。
- [ ] 测试覆盖正常流、取消、超时、半流失败、降级和晚安收束，并有一条 UI 集成测试验证可见节奏。
