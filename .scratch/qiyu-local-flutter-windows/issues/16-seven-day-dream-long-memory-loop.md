# 16 — 实现七天 Dream 的长期印象闭环

**What to build:** 在满足睡眠窗口和最短七天间隔时，对近期已整理记忆进行一次保守的深层重组，产出长期印象，并让经过验证的结果影响下一次聊天。

**Blocked by:** 11「打通 Open-loop 自然跟进生命周期」、12「打通关系阶段、温度与行为变化」、15「完成月压缩与跨月召回」

**Status:** ready-for-agent

- [ ] Dream 只有在用户晚安后、宿主仍可运行且距上次成功 Dream 至少七天时才具备执行资格。
- [ ] 日终整理每天可执行，但绝不会重置或绕过 Dream 的七天间隔。
- [ ] Dream 输入只包含必要的已 finalized 摘要、月度压缩、关系状态和未完线索，遵守上下文预算。
- [ ] 先生成独立草稿，再执行结构、证据、敏感信息、用户控制和相互矛盾检查；全部通过后才原子接纳。
- [ ] 长期印象只保留高压缩的生活倾向、持续关注和关系变化，不保存产品机制或逐日流水账。
- [ ] 接纳后的长期印象进入下一次聊天热层，并能在回复中产生可观察但不过度直白的连续性。
- [ ] 中断、程序退出、模型失败或草稿验证失败不会更新上次成功时间，也不会破坏旧长期记忆。
- [ ] 测试使用可控时钟覆盖少于七天、正好七天、无晚安、重复触发、失败重试、原子接纳和下一轮生效。
