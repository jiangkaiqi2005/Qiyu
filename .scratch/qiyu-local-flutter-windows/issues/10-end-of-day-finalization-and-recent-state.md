# 10 — 完成日终归档与近日状态重建

**What to build:** 将一天内的增量记录整理为稳定的日终状态包，并在晚安、日期变化或下次启动时可靠补做，供后续关系、跟进和召回使用。

**Blocked by:** 09「实现伪 Agent 白名单动作与增量 Episode」

**Status:** done

- [x] 用户明确晚安后可触发日终整理，但不会因此立即触发 Dream。
- [x] 日期变化或程序启动时能发现尚未完成的前一日，并安全补做整理。
- [x] 日终流程按固定顺序更新当天摘要、待跟进候选、关系证据和索引，再标记 finalized。
- [x] finalized 只在全部必要写入成功后设置；中途失败可从 checkpoint 幂等重试。
- [x] 最近状态包保持严格预算，只保留下一次聊天需要的近期事实、情绪余波和未完事项。
- [x] 无有效对话、只有系统错误或只有敏感信息的一天不会制造虚假记忆。
- [x] 测试覆盖晚安、跨日、启动修复、部分失败、重复执行和无有效内容场景。
