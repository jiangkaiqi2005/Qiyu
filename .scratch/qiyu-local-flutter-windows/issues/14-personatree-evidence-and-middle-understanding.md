# 14 — 建立 PersonaTree 叶节点与中间理解

**What to build:** 将多次对话中稳定、可回溯的用户信号组织为 PersonaTree 证据叶节点，并在证据足够时形成保守的中层理解，避免把单次情绪写成人格结论。

**Blocked by:** 09「实现伪 Agent 白名单动作与增量 Episode」

**Status:** done

- [x] 叶节点只保存与理解用户有关的最小证据引用、时间、主题和置信信息，不复制整段敏感原文。
- [x] 相同或近似信号可以合并计数，矛盾信号并存而不是静默覆盖。
- [x] 中层理解必须由跨时间的多条证据支持，单轮自述、玩笑或临时情绪不足以形成稳定判断。
- [x] 每个中层理解可以追溯到全部支持与反对证据，并记录形成和最近复核时间。
- [x] 新证据可以降低、暂停或撤销旧理解；被撤销的结论不再进入聊天热层。
- [x] 敏感信息过滤和用户禁止提及高于 PersonaTree 提炼，不得通过抽象改写绕过删除或遗忘。
- [x] 测试覆盖重复证据、矛盾证据、证据不足、置信下降、撤销和跨重启重建。
