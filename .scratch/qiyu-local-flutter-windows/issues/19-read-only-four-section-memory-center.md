# 19 — 提供四区只读记忆中心

**What to build:** 提供一个克制、可理解的记忆中心，让用户浏览最近发生、长期印象、关于你和我们的关系四类本地记忆，并看清它们从哪里来。

**Blocked by:** 07「提供跨重启的每日记录与历史浏览」、13「实现两级索引与'晚一拍想起'」、15「完成月压缩与跨月召回」、17「完成 Dream 根节点、Persona 与共同过往」

**Status:** done

- [x] 记忆中心明确分为最近发生、长期印象、关于你和我们的关系四个区域，不暴露内部实现术语作为主要导航。
- [x] 每个条目显示用户能理解的内容、形成时间、最近更新时间、置信或状态以及可用的证据入口。
- [x] 用户可以从长期结论逐层查看支持摘要，再定位到相应日期或会话证据。
- [x] 未形成某类记忆时展示诚实的空状态，不用示例数据或模型生成内容填充。
- [x] 默认不直接展示敏感原文；冻结、禁止、冲突和待复核状态有清晰但不惊扰的标识。
- [x] 浏览和展开证据不会触发模型调用、重新整理、关系变化或隐式写入。
- [x] Widget 和集成测试覆盖四区加载、空状态、证据追溯、局部损坏、敏感遮罩和只读保证。

**Resolution（2026-08-18）：**

- Host 新增 `memory_center.dart`：`GET /api/memory` 四区总览 + `GET /api/memory/items/{opaqueId}` 详情；opaque ID 进程内注册表，不含路径；不持有模型客户端与写入器，构造上杜绝模型调用与隐式写入。
- 四区映射：最近发生 ← 近 31 天 episodes（记忆/关注的事/关系变化三类，簿记条目不展示）；长期印象 ← long-memory 三分区（共同过往归入「我们的关系」）；关于你 ← PersonaTree 根/中间理解/叶三层；我们的关系 ← relationship 受管结构 + 共同过往。
- 读取时纪律全覆盖：episodes、long-memory、persona、relationship 各行均走敏感遮罩（手机号/邮箱/密钥残留）与冻结/禁提标识；冲突叶「冲突」、有冲突中间理解「有冲突证据」、待稳定事实与未归档日「整理中」轻标识。
- 证据链：根 → 中间理解（形成/复核时间）→ 叶（日期/来源性质/关系）→ 当日记录 → 条目（摘录）→ `/history/{sessionId}` 当时对话。
- Flutter 新增 features/memory（client/view-model/view）与首页「记忆」入口（ticket 08 衔接）；只读，无编辑/控制/揭示动作（归 ticket 20）。
- 验证：Host 299 / Flutter 43 测试、verify:migration-baseline 全绿；浏览器真实测试 10 张截图 + 只读红线目录快照一致（.scratch/ticket19-browser/浏览器测试记录.md）。
- 已知设计边界：long-memory 条目按 T03 定稿形态不携带时间戳与证据指针，记忆中心不伪造；其追溯职责由「关于你」三层承担。
