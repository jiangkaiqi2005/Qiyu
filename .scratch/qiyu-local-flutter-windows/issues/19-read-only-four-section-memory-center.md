# 19 — 提供四区只读记忆中心

**What to build:** 提供一个克制、可理解的记忆中心，让用户浏览最近发生、长期印象、关于你和我们的关系四类本地记忆，并看清它们从哪里来。

**Blocked by:** 07「提供跨重启的每日记录与历史浏览」、13「实现两级索引与‘晚一拍想起’」、15「完成月压缩与跨月召回」、17「完成 Dream 根节点、Persona 与共同过往」

**Status:** ready-for-agent

- [ ] 记忆中心明确分为最近发生、长期印象、关于你和我们的关系四个区域，不暴露内部实现术语作为主要导航。
- [ ] 每个条目显示用户能理解的内容、形成时间、最近更新时间、置信或状态以及可用的证据入口。
- [ ] 用户可以从长期结论逐层查看支持摘要，再定位到相应日期或会话证据。
- [ ] 未形成某类记忆时展示诚实的空状态，不用示例数据或模型生成内容填充。
- [ ] 默认不直接展示敏感原文；冻结、禁止、冲突和待复核状态有清晰但不惊扰的标识。
- [ ] 浏览和展开证据不会触发模型调用、重新整理、关系变化或隐式写入。
- [ ] Widget 和集成测试覆盖四区加载、空状态、证据追溯、局部损坏、敏感遮罩和只读保证。
