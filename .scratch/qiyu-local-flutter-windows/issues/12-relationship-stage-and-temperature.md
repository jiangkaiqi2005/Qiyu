# 12 — 打通关系阶段、温度与行为变化

**What to build:** 根据长期互动证据维护只升不降的关系阶段和可缓慢波动的关系温度，并让它们真实改变栖语的表达边界。

**Blocked by:** 10「完成日终归档与近日状态重建」

**Status:** ready-for-agent

- [ ] 关系阶段沿初识、熟悉、朋友、深交单向升级，单次热聊或模型主观判断不能越级。
- [ ] 升级依据来自可追溯的互动数量、时间跨度、相互回应和稳定关系证据。
- [ ] 关系温度可以缓慢变化，但不能绕过阶段所限制的调侃、主动性和旧事引用权限。
- [ ] 阶段和温度共同影响回复策略、称呼距离、主动跟进和共同过往引用，而不是只显示一个数值。
- [ ] 用户边界、安全规则和禁止提及始终高于关系亲密度。
- [ ] 重启、日终重复执行和旧记录补算不会导致关系倒退或重复升级。
- [ ] 测试覆盖阶段阈值、温度变化、权限差异、边界优先级和跨重启一致性。
