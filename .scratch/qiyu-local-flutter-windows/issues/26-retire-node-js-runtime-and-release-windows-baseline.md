# 26 — 收缩旧 Node/JavaScript 运行时并发布基线

**What to build:** 在所有首发能力都已由 Dart/Flutter 路径承接并通过发布验收后，移除产品对旧 Node/JavaScript 运行时的依赖，形成清晰的 Windows 首发基线。

**Blocked by:** 25「产出 Windows 安装包与本机安全验收」

**Status:** ready-for-agent

- [ ] 建立首发能力对照清单，证明聊天、安全、Provider、记忆、Dream、历史、设置、备份和诊断均由新运行时承接。
- [ ] 新旧实现对共享行为契约的必要结果一致；有意改变的行为必须回到 Spec 说明，而不是静默漂移。
- [ ] 删除或归档产品运行所需的旧服务入口、旧页面和旧专用配置，安装包与启动流程不再调用 Node。
- [ ] 只清理因本次收缩而失去用途的代码和测试，不顺手重构无关内容或删除用户现有工作区改动。
- [ ] 更新面向用户和执行 Agent 的启动、测试、打包、数据位置及故障排查说明，使其只描述当前基线。
- [ ] Dart 单元测试、Flutter 测试、集成测试、行为契约、Windows 安装验收和敏感信息扫描全部通过。
- [ ] 最终候选版本在无 Node 环境中完成首次启动、配置、聊天、重启、Dream 时间模拟、备份恢复和卸载验证。
- [ ] 明确记录 iOS 与 Android 为后续适配范围，不在本票引入移动端实现、云同步或旧数据迁移。
