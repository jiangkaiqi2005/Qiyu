# 图标参考研究

研究日期：2026-09-14。以下是对公开图形的视觉分析与本次设计判断，不是品牌方对栖语的评价。参考案例仅用于研究，交付资产不含其标志素材。

| 案例与来源 | 观察 | 对栖语的作用 |
| --- | --- | --- |
| [Woolmark](https://www.woolmark.com/about/the-woolmark) | 连续曲线、重复节奏和负形共同构成完整符号 | 曲线应有连贯方向；不借用三向编织骨架 |
| [MUBI](https://mubi.com/logo) | 简单圆点依靠固定数量与位置关系建立识别 | 限制元素数量，以稳定关系建立个性 |
| [Vertical / Pentagram](https://www.pentagram.com/work/vertical) | 简化蜂鸟轮廓仍能表现生命与运动 | 鸟形可以省去五官；栖语采用收翼停歇的姿态 |
| [Battersea / Pentagram](https://www.pentagram.com/work/battersea/) | 用有限轮廓和动物特征传递性格 | 亲近感不依赖表情，避免增加宠物式眼睛 |
| [Mastercard / Pentagram](https://www.pentagram.com/work/mastercard) | 少量基本形状形成稳定关系 | 先检验单色轮廓，避免靠材质补救弱形状 |
| [Endel / App Store](https://apps.apple.com/us/app/endel-focus-sleep-sounds/id1346247457) | 黑白强对比，内部连续曲线与外形协同 | 夜色背景配明亮主体；内部只保留一条翼缝 |
| [Headspace 品牌规范](https://live.standards.site/headspace/logo) | 带有轻微不规则的圆形，比完美几何更亲近 | 外轮廓允许自然的不对称，不堆叠规则几何 |
| [Gentler Streak / App Store](https://apps.apple.com/es/app/gentler-streak-activity-log/id1576857102?l=en-GB) | 饱满体量与少量凹口产生柔和性格 | 用饱满腹部与小喙切口建立特征 |
| [Finch / App Store](https://apps.apple.com/tw/app/finch-self-care-pet/id1528595748) | 大面积鸟脸裁切，五官和颜色很醒目 | 对照不同的亲近感路线；栖语保持无五官剪影 |
| [Portal / App Store](https://apps.apple.com/us/app/portal-escape-into-nature/id1436994560) | 深底与有限发光色营造沉静感 | 控制明暗，避免细密光环在小尺寸中破碎 |

## 最终取舍

三种新纯图形先分别生成，再去掉材质并排比较。回声图形偏向音频/RSS，扭转环偏向常见技术标识；归鸟在单色下保留了完整形象和安静姿态。用户明确选择归鸟。

「会记得你」不被强行拆成眼睛、记忆点、无限环等附加符号。图标承接归来与熟悉感，保持一个简单、可重复识别的形象。主标为单色，应用版本保留很轻的月白渐变。
