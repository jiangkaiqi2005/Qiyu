# 栖语 · 归鸟

一天结束了，有些话还没找到人说。

图标是一只收拢翅膀、安静停下来的鸟。它呼应「栖」的停歇与归来；回到熟悉之处的感觉，承接栖语「会记得你」的特点。图形只保留鸟的外轮廓和一条弧形翼缝，用姿态表现亲近与安静。记忆本身仍由产品体验兑现，不要求观看者从图标里解出全部功能。

用户已从三种纯图形中选定「归鸟」。图标本体没有汉字、英文字母或首字母变形。

## 已确认的两端用法

- **Web：黑色归鸟。** 独立矢量是 `svg/qiyu-web-mark.svg`，浅色底的网站图标是 `svg/qiyu-web-icon.svg` / `png/qiyu-web-icon-1024.png`。已接入 Flutter Web 的网站图标、安装图标和页内品牌入口；深色界面中使用浅色底托保证黑色轮廓可见。
- **APP：用户提供的粉黑质感原图。** 原图保存在 `png/qiyu-app-master.png`（1254×1254，原样复制），标准尺寸为 `png/qiyu-app-icon-1024.png`。已接入 Android 各密度启动图标、Android 8+ 自适应图标和原生应用内品牌入口。

Android 只按平台尺寸缩放原图，自适应图标保留安全留白；没有重新生成或改变用户选定的图案。下表中的轻渐变 SVG 为同一鸟形的可编辑版本，APP 正式选用上面的粉黑质感 PNG。

## 使用

| 文件 | 用途 |
| --- | --- |
| `svg/qiyu-mark.svg` | 深色单色主标，透明底 |
| `svg/qiyu-mark-light.svg` | 浅色反白主标，透明底 |
| `svg/qiyu-icon.svg` | 夜色底、月白微渐变应用图标 |
| `svg/qiyu-icon-flat.svg` | 单色应用图标 |
| `svg/qiyu-icon-light.svg` | 浅底应用图标 |
| `svg/qiyu-icon-micro.svg` | 16–24px 小尺寸版；扩大翼缝，使用单色 |
| `svg/qiyu-icon-maskable.svg` | 平台遮罩图标；不透明方底，主体位于中央安全圆内 |
| `svg/qiyu-lockup.svg` | 图形与「栖语」品牌名组合；独立图标不含文字 |
| `png/` | 16–1024px 图标和透明底主标 |
| `qiyu.ico` | 16/24/32/48/64/128/256px 多尺寸图标 |
| `source/symbol-paths.json` | 主轮廓、翼缝、小尺寸翼缝和材质层路径 |

主标用单色，应用图标可用轻微渐变。保持现有比例和留白。16–24px 使用专用小尺寸文件；不要给鸟添加眼睛、脚、树枝或更多装饰。SVG 均由可编辑路径组成，不含嵌入位图或字体依赖。
