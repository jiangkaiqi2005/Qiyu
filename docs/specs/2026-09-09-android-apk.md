# Spec：栖语安卓版·端内形态（android-embedded）

状态：**待放行**（triage 词汇 `ready-for-agent`，用户放行后即拆票开工）。grill-with-docs 拷问九问定案 2026-09-09；关联 ADR `docs/adr/0009-android-embedded-form.md`、词汇表 `CONTEXT.md`「形态」节（端内形态／平台壳／手动导出）。本文件按 to-spec 模板发布，取代同目录 2026-09-09 早版草稿。

## 问题陈述

栖语现在只能活在 PC 上：Windows 本机 Host 开机、浏览器打开 loopback 页面才能用。睡前陪伴最常用的场景反而是躺在床上、关灯、放下电脑的时候——恰恰是栖语缺席的时刻。用户想在安卓手机上使用栖语，但现有仓库形态（Flutter Web UI ＋ Dart Windows Host）没有一条「直接 build 出 APK」的路：UI 是 web-only，Host 的凭据存储与开机引导是 Windows 专属。

## 方案

一个安卓 APK，内含全部三层：纯 Dart 行为核心、平台无关 Host 服务、原生编译的 Flutter UI。会话、记忆、Provider Key 只存在手机上，PC 不开机也能用；跨设备只靠手动导出/导入（「端内形态」，见词汇表）。PC 版（Windows Host ＋ web UI）原样保留，安卓是增量不是替代。安全模型不搬家不改形：Host 服务在 App 进程内监听 127.0.0.1 随机端口，会话／同源 Origin／CSRF／交付校验原样保留。

## 实现决策

拷问定案（九问）：

1. **形态＝手机自成一体**：APK 内含行为核心＋Host 服务＋原生 UI；数据与 Key 只在手机；跨设备只靠手动导出。拒绝远程显示器（PC 必须开机、削弱安全模型）与云端 Host（违反隐私红线）。
2. **UI＝Flutter 原生编译**：不走 WebView 套壳。现有四个浏览器专属实现（录音、播放、备份下载、折叠状态）的条件导入缝就是预留接缝，各写一份 Android 实现。拒绝套壳的理由：麦克风权限桥接、返回键、下载监听干完也是弃子，且 Flutter Web 包在 WebView 里启动重。
3. **Host 接线＝进程内 loopback HTTP**：App 启动时监听 127.0.0.1 随机端口，UI 显式指向该地址。会话／Origin／CSRF／「页面绝不能看到未经安全校验的原始 token」全部原样保留。拒绝直调行为核心：省微秒级开销，代价是拆安全卡口、两端分叉。
4. **凭据＝Key 主存本机 `provider.json`，凭据仓只做迁移回退与旧值清理**（2026-09-09 裁定，PC 与安卓同构；原文写「凭据＝Android 系统安全存储」，读作 Key 主存进 Keystore，与实际不符）：凭据仓接口定义在平台无关包，Windows 凭据管理器实现留在 Windows 壳，Android 实现在安卓壳注入（Keystore 支撑），两侧实现供 Host 读取回退与切换 Provider/URL 时清理旧 scope 值。Host 纯 Dart 包不碰 Flutter 插件。
5. **数据＝App 私有目录＋手动导出**：会话与记忆 Markdown 落 App 沙盒内同构目录（与词汇表「记忆目录」的移动端条款一致）；导出复用现有备份通道接系统分享 sheet。
6. **Provider＝三路全要**：豆包直连零新增；OpenAI 兼容／Anthropic 需要 App 内代理配置（作用于模型网关的 HTTP 客户端，设置页加代理块）；局域网 Ollama 直连家里电脑（无密钥），Android 网络安全配置默认禁明文、仅放行用户显式配置的私有网段地址。
7. **包结构＝抽平台无关包**：Host 平台无关逻辑（shelf 站点、交付编排、记忆节奏、模型网关、Markdown 持久化、凭据仓接口）抽成 `qiyu_local_host`；`qiyu_windows_host` 变薄（启动入口＋凭据管理器实现＋开浏览器）；qiyu_flutter 新增 android 目录成为安卓壳，依赖 `qiyu_local_host`。拒绝条件排除方案：「windows_host 跑安卓」名实不符，扭曲长期生息。
8. **门禁＝壳薄、CI 不跑安卓构建**：`qiyu_local_host` 测试随代码搬家、全绿，覆盖率水位按搬家后实测立基线只升不降；现有三包水位（core 88／host 91／flutter 91）不动；安卓构建本地脚本＋真机冒烟兜底。
9. **节奏＝spec 放行后写码**（本文件）；T1 抽包重构完成前不写安卓一行代码。

改动面：

- **行为核心与契约不动**：本地规则引擎（行为基准、golden 锁定输出）零改动，行为、人格、提示词、记忆方案零改动——本次是工程迁移，不碰设计笔记管辖的行为面。
- **新包**：`qiyu_local_host`（平台无关 Host 核心＋凭据仓接口）。
- **Windows 壳变薄**：保留启动入口、Windows 凭据仓实现、开机引导浏览器；其余改依赖新包。
- **Flutter 双平台化**：新增 android 目录与启动装配（先起 Host 拿端口、再跑 UI）；UI 与 Host 的连接方式按平台分岔——web 维持现状同源相对路径，安卓显式指向 loopback；地址改造集中在各 client 共用的地址解析接缝一处，领域 client 不感知。
- **原生 http 客户端接管浏览器免费提供的部分**：从引导响应接住会话 Cookie 并回传；变更请求带同源 Origin 与 CSRF token。机械活，漏了全线 401，列验收第一项。
- **四个平台实现的 Android 侧**：麦克风录音（系统权限弹窗，音频编码契约与 web 实现对齐）、朗读播放（音量／静音本地持久化语义不变）、备份导出（系统分享 sheet／保存到用户可见目录）、折叠状态（本地 KV）。
- **签名**：第一天自建 release keystore 并离线备份（2026-09-09 定案）。红线：换 keystore＝签名不匹配＝无法覆盖安装＝必须卸载＝私有目录记忆全丢。包名定案 `dev.qiyu.app`。
- **生命周期**：不做后台常驻；记忆节奏靠启动补扫与空闲补办（与 PC 行为一致）；聊天中切后台沿用现有取消语义。
- **落地时同步** AGENTS.md「仓库形态」段与构建命令、覆盖率水位脚本条目。

## 测试决策

只测外部行为，不测实现细节。**复用三条既有缝＋平台第二实现，零新缝**：

1. **Host HTTP 面（最高缝）**：抽包后现有 Host 行为测试全部原缝照跑——三 Provider 正常终止／提前 EOF／超时／原生错误／订阅取消、requestId 幂等、晚安日终、本地回退、记忆节奏不阻塞首个回应。先例：本机服务注入式测试模式。安卓壳复用同一 HTTP 面，Host 侧因此零新缝。
2. **Flutter client／widget 层**：地址接缝与 Cookie／Origin／CSRF 接管用进程内真 127.0.0.1 测试服务器在 dart 测试里断言（回传、头流转、未接管即 401 的反面用例）；等待态、增量可见节奏、停止按钮、最终只提交一次沿用现有 widget 测试先例。
3. **凭据仓接口**：fake 实现测 Host 行为；Windows 与 Android 真实现不进 dart 测试（凭据管理器／Keystore 的真意 fake 不出来），归真机冒烟。
4. **平台条件导入缝**：四个缝各添 Android 第二实现而不加缝；dart 层测契约对齐（录音块格式、播放器音量持久化、导出载荷、折叠 KV），真机行为（权限弹窗、系统分享、实际发声）归冒烟清单。不在 dart 测试里 mock 平台通道。

门禁按仓库惯例：流式改动覆盖多 Provider 场景；全量交付门禁跑通；新包水位进覆盖率门禁脚本。

## 范围外

- iOS；后台常驻、推送、定时任务调度器。
- 自动云同步、多设备实时同步、远控 PC 版 Host。
- 行为、人格、提示词、记忆方案的一切改动（工程迁移，设计笔记定稿不动）。
- 本地规则引擎兜底回复的任何变化；行为契约与 golden 不动。
- 旧 Node/JS 轨道复活；localStorage 升级为任何设备的主持久化。
- 平板专属布局（窄屏形态已按唯一判据覆盖）。
