# 桌面侧边栏可收起 — 用户裁定规格（2026-08-31 二次裁定版）

> v1（同日早）按「图标收起 + 面板内独立回合一页入口」落地，实机验证被用户否决，
> PR #5 已关闭。本文件为二次裁定版，v1 全文作废。

## 背景
栖语桌面端（宽度 ≥ `QiyuLayout.desktopBreakpoint`）左侧 240px 毛玻璃侧边栏常驻，
用户反馈「左边栏默认打开，但是收不回去」。

## 裁定（用户 2026-08-31 实机验证后确认）
1. **图标是纯开合开关**：桌面点击左上角栖语品牌图标 = 切换侧边栏收起/展开。
   点击**不带任何导航语义**，不回合一页、不跳路由。
2. **「回合一页」入口删除**：桌面端不设任何形式的「回合一页」入口
   （v1 往面板里加的独立导航项是超出需求的东西，删掉）。
3. **图标位置恒定**：侧边栏开或关，品牌图标必须在**同一位置**。
   图标不能放在会随收起动画进出的容器里；它应是一个常驻层，
   面板在它旁边/下方收起展开。
4. **无残留**：收起过程中图标不得出现「先留着再消失」或复制两份的视觉残留；
   图标本身不参与进出树或淡入淡出，全程只有面板在动。
5. **状态不持久化**：刷新/重启回到默认展开。
6. **窄屏不受影响**：窄屏抽屉（三条杠）整体不动，抽屉里品牌槽仍是
   「点击回合一页」（测试键 `go-home` 只保留在抽屉品牌槽上）。
7. **动效**：面板收起/展开沿用 `QiyuMotion` 口径，reduced-motion 归零；
   过渡期间图标矩形必须逐帧不变。
8. **无障碍**：图标键盘可达（焦点环）、有 tooltip 与显式 Semantics 标签
   （开合两态的标签分别说清「收起侧边栏」「展开侧边栏」）。

## 验收（实机判据，用户会亲自看）
- 宽屏点品牌图标：面板收起，图标纹丝不动；再点：面板展开，图标仍在原处。
- 收起/展开全程图标无重影、无位置漂移。
- 桌面上找不到任何「回合一页」入口，点图标也不会跳转。
- 窄屏三条杠抽屉与其中品牌槽行为与改造前一致。
- `flutter analyze` 干净、`flutter test` 全量绿。
