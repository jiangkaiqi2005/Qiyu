# 点页内返回键时整页跳一下

## 现象

从挂壳页（对话 / 历史 / 记忆中心 / 设置）进到页内详情（某一天、某条记忆、诊断、隐私），点左上角返回键回到挂壳页时，整个页面还要跳一下。侧边栏四页之间切换已经不跳了（上一轮修过），跳的只剩详情页进出这一段。

## 已侦察到的结构事实（供起点参考，结论以实测为准）

- 四条挂壳路由收在同一个 ShellRoute 下，壳页与壳下内容页都走 `NoTransitionPage`，壳 State 跨导航存活——这一层已无过渡。
- 页内详情是 ShellRoute **之外**的顶层 GoRoute，`app.dart` 注释明说它们「保留各自的默认路由过渡（不在壳页之列）」——默认 MaterialPage 过渡在进详情与返回时各播一次整页动画，这就是要修的对象。
- 进入详情走 `openInFront`（栈里没有目标就 `push`），返回走 `backToPrevious`（能 pop 就 `pop`），实现在 `lib/features/navigation.dart`。
- 详情页不挂壳（决策日志第五轮 #9），自带页内返回。

## 验收判据

1. 从挂壳页进详情、点返回回挂壳页，两个方向全程无可观察的整页跳闪/动画重放；详情页出现与消失平静。侧边栏与品牌图标全程稳定。
2. 补回归用例锁住，反证做过——把过渡收敛退回默认，用例当场判红。
3. 导航语义一项不动：`go` / `push` / `openInFront` / `backToPrevious` 的调用点与语义不改，详情页之间成环回退的闸门（`openInFront` 里逐层 pop 的逻辑）不改；详情页仍不挂壳、仍自带页内返回；聊天页工具条的 push 行为不变。
4. 若保留任何过渡，遵守 design-system §9：时长取 `qiyuMotion()` / `QiyuMotion` 既有档位，reduced-motion 下一律立即到位；不凭观感自造新档位、新色值、新间距（裸色与裸间距有棘轮扫描）。
5. 既有测试全绿：`apps/qiyu_flutter` 下 `flutter analyze` 与 `flutter test`。修法若动路由表，消费 `qiyuRoutes()` 的测试断言要跟着改得仍锁原行为，不是删断言绕过。

## 范围红线

- 只动这一件事。不顺带重构、不顺带格式化未触碰文件、不改主题与其它页面视觉。
- 修法方向自己判断并实测验证：「把详情页的路由过渡收敛成与壳页一致的平静形态（无过渡或统一轻过渡，经 pageBuilder 层）」是当前结构下最可能成立的方向，不是命令——若有更小、更能守住现有断言的修法，用它。
