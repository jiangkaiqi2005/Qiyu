# Spec：热层读取指纹缓存（方向 A）

状态：待放行（grill-with-docs 对齐 2026-09-08；决策记录见 `docs/adr/0008-hot-layer-fingerprint-cache.md`）
改动面：`apps/qiyu_windows_host/lib/src/state_pack_reader.dart` ＋ 其测试；不动契约、不动系统提示词、不动 golden、不动其他模块

## 背景与目标

- 每轮回复 `StatePackReader.readHotLayerBlocks` 全量重读六个文件（open-loops / relationship / daily-state / long-memory / persona / memory-controls）再过滤解析。文件多数轮次无变化，重复读取是纯浪费。
- 目标：无变更轮次复用读取与解析结果，注入内容与现状逐字节一致——可观测行为不变，只省 IO。
- 非目标：不改注入内容与过滤/裁剪/候选逻辑；不给记忆中心 UI 加缓存；不做跨进程或持久化缓存；不新增常规命中/未命中日志；不改系统提示词（静态块 const，动态块命中时逐字节一致，时刻前缀与跟进候选仍每轮计算）。

## 设计

1. 缓存位置：`StatePackReader` 进程内字段；仅注入路径（`readHotLayerBlocks` 唯一消费方是聊天交付）。
2. 缓存对象：各源文件的原始文本与解析结果，含 memory-controls 的受控标题集合。过滤、跨块 3000 裁剪、跟进候选、纪律文案每轮重算（纯内存微秒级）——行为逻辑零缓存，票 04/05 部分成功语义全部保持在每轮执行的活代码里。
3. 指纹：改动时间＋大小，每轮回复对全部源文件 stat 一遍；未变 → 复用，变化（含从有到无）→ 重建。
4. 文件缺席是合法指纹：缓存「不存在/空」态，不当作错误。
5. stat 报错（权限/IO 异常，非缺席）：视为指纹不匹配，重建；重建失败走既有部分成功语义（该层 null → 本轮该块空缺），绝不沿用缓存冒旧（用户裁定 2026-09-08，推翻初选的沿用缓存）。
6. 并发：Dart 单 isolate 内无锁；并发未命中各自重建，同值幂等，后写覆盖。
7. 受控集合：单次装配内三次消费共享一次解析（指纹校验一次）；更新既有「不并行、不缓存、不共用快照」注释与类文档为新语义。

## 实施要点

- 注入 stat seam（假指纹、假错误、读计数），沿 Host 既有「抽象接口注入时钟/原子写入」惯例；默认实现用 `File.stat`。
- 文件读取经带指纹校验的缓存入口（现有 `readFileIfExists` 语义保持：不存在返回 null）；`OpenLoopStore` 等写路径不改——任何写入自动改变指纹。
- 缓存不持久化、不跨 Host 重启。

## 测试计划

- 既有 state_pack_reader 测试断言原样全过——行为不变即验收判准。
- 新增：指纹未变命中缓存（读计数断言）；单文件变化后该层重建、其余层命中；从有到无；stat 报错 → 重建；重建失败 → 部分成功语义（该块空缺、其余层照常）；并发未命中不崩不脏读。
- 门禁：host 包 `dart analyze && dart test`；交付前三包全量＋覆盖率水位（host 91 不降）。
