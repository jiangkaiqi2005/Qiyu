# 栖语 Web 设计系统规范 (Design System)

本规范服务于当前 Flutter Web 实现（`apps/qiyu_flutter`），2026-08-27 定稿。此前服务于旧 Web 产品线的暖金黑夜色版本已废弃（旧线已于 Ticket 26 退役），本文档为原地重写。

## 1. 方向与基调

偏紫的暗夜色调：安静的夜里氛围。温暖靠克制与留白表达，不靠暖色堆叠。

- 高级 = 小、轻、暗角重；不堆视觉重量，不搞霓虹发光、玻璃堆叠。
- 颜色只存在语义 token 一层，组件只准消费 token，禁止直接写色值。
- **三色纪律**：紫住强调（发送按钮、焦点描边），暗红住危险，其余表面、线条、选中态一律中性暗夜色。危险只有两类：**破坏性操作**（删除、清除产品数据）与**故障/失败态**（本机 Host 不可用、某个动作没成）。这两类之外禁用暗红，非强调位禁用紫。故障本身就是危险态，所以连接状态探测失败时圆点与文案转 `danger`（见第 5 节）是故障态的一例，不是这条纪律的例外。
- **紫的合法出口就是「强调位」这一个语义**，不按控件形状数：玻璃紫的主按钮与发送钮、`accent-bright` 的键盘焦点环，以及§8 组件 2 那种无底色的文字按钮 / 次按钮（它承担的是「点这里去做那件正事」，属强调位）。判定看这一处是不是强调，不看它是不是按钮。「除了发送按钮和焦点外没有紫」这句说的是**表面不发紫**——底色、描边、选中态、悬停底一律中性。
- 组件统一复用：Material 3 内置组件打底 + 栖语薄包装层，零第三方 UI 库依赖。

## 2. 语义色板 (Color Tokens)

| 角色 | Token | 值 | 用途 |
|---|---|---|---|
| 底色 | `night` | `#0f0e14` | 页面背景（近黑） |
| 面板 | `panel` | `#181719` | 卡片、侧边栏与抽屉的基色（中性暗） |
| 字色 | `ink` | `#ece9f2` | 正文（暖调象牙白偏紫） |
| 次要字 | `muted` | `#9a94a8` | 次要文字、占位符 |
| 强调-交互 | `accent-glass` | `rgba(75,64,146,.62) → rgba(51,43,97,.5)` 半透明渐变 + 背景模糊 | 发送按钮（玻璃紫，无描边无白色高光） |
| 强调-状态 | `accent-bright` | `#9d8fe0` | 焦点描边、键盘导航 |
| 图标近白 | `on-accent` | `#f5f3fa` | 强调底色上的图标/文字 |
| 用户气泡 | `bubble-user` | `#28272e` | 用户消息气泡（中性暗，无描边） |
| 描边 | `line` | `#232227` | 发丝描边（中性暗） |
| 危险 | `danger` | `#cc9999` | 破坏性操作（删除、清除产品数据）与故障/失败态（Host 不可用、动作没成），降饱和暗红；非这两类禁用 |

毛玻璃 = **`rgba(19,18,23,0.72)`** + 背景模糊（模糊半径 16–24px，实现时凭视觉验收微调）。它比 `panel` 暗一档、自成独立 token，不从 `panel` 拼透明度得出——目的就是不透背景紫；`panel`（`#181719`）只作卡片与面板的实底色。选中态用中性暗底 `rgba(255,255,255,0.04)`，不用紫色底。

既成事实登记：`danger` 在主题层**同时占两个字义槽**——`ColorScheme.error`（字档）与 `ColorScheme.errorContainer`（容器底），即 `lib/theme/qiyu_theme.dart` 里 `error:` 与 `errorContainer:` 这两处赋值（截至提交 `387fc4a` 位于 `:214`、`:216`；行号会随文件漂移，核验请按槽位名）；`lib/features/settings/diagnostics_view.dart:292` 的强调诊断芯片确实拿它当**底色**渲染。本节把它当字档写的用法不覆盖这一处，两处并存是现状。

## 3. 字体 (Typography)

全局唯一字族：**思源宋体（Noto Serif SC）**，OFL 授权，由一次性资产准备脚本裁出静态子集随包入库（不做构建期子集化；子集必须覆盖的字区清单见 Spec `docs/superpowers/specs/2026-08-28-qiyu-web-purple-night-visual-revamp.md`）。不引入第二套字族；精细靠字号与字重，不靠换字体。

`pubspec.yaml` 中的 `Roboto` 别名保留并改指新宋体资产：它是 2026-08 修「字体回退卡死」时为防止未随包字族触发远程回退而设，删掉会重新引入同一 bug。

字阶（精美优先，宁小勿大）：

| 级别 | 字号 | 用途 |
|---|---|---|
| 问候语 | 22 | 空状态首页问候 |
| 标题 | 18 | 页面标题 |
| 正文 | 15 | 消息与正文；栖语的话行高 1.9 |
| 次要 | 13 | 时间戳、说明文字 |
| 极小 | 12 | 徽标、脚注 |

## 4. 图标

Material Symbols 系、统一 outlined 风格、24px，**描边 1.2 细线条**（粗描边是模板感/AI 感的元凶，禁用）；优先选曲线图形，避免方正机械的图形。不混用其他图标库。

定案选型：

- 导航三件套：**沙漏**（历史，时间流过）、**翻开的书**（记忆中心，两页弧线）、**圆形旋钮滑杆**（设置）。
- 记忆四区：时钟（最近发生）、山形（长期印象）、单人（关于你）、双人（我们的关系）。
- 记忆操作：铅笔（编辑）、雪花（冻结）、禁止圈（禁提）、垃圾桶（删除）、眼睛（临时查看）。
- 被拒：方正日历、齿轮、自造抽象图形（「波纹入皿」因看不懂被弃）——图标求一眼懂，不求炫技。

**细描边怎么拿到的（实现机制）**：Flutter 内置的 `Icons.*` 是定宽字形，`Icon` 也没有 `strokeWidth` 入口，「1.2 细描边」在内置图标下**做不到**。定案＝引入 **Material Symbols Outlined 的 ExtraLight（wght 200）静态实例**，用一次性脚本裁出本轮用到的字形（45 个码位、7KB）入库为 `assets/fonts/MaterialSymbolsOutlined-QiyuSubset.ttf`，码位常量集中在 `lib/theme/qiyu_icons.dart`，字族名走 `QiyuIconSpec.fontFamily`。取静态实例而非可变字体的原因：静态实例把字重烘进轮廓，不需要运行时字轴支持。实测描边 `40/960 em` ≈ **1.00px @24px**（wght 300 为 1.50px、400 为 2.00px），取最接近 1.2 且偏细的一侧。字体为 Apache-2.0，许可证与出处随包入库。裁剪脚本属一次性资产工艺，留 `.scratch/` 不入库、不进发布门禁。

例外：`ExpansionTile` 的展开箭头由 SDK 自带（换掉就丢旋转动画），仍走内置字族；这类框架内部图标不作强制项。

## 5. 布局与导航

### 合一页

首页与对话页是**同一个页面的两种状态**：无消息时空状态即首页（背景图 + 问候语 + 输入框）；发出第一句，背景与问候淡出、消息流生长。没有独立的「首页→对话页」跳转；从历史打开旧会话是同一页面的「已有消息」状态。

两态的判定口径：**会话恢复中不算空态**。旧会话恢复期间消息列表暂时为空，若此刻算作空态，打开应用会先闪一帧首页（背景 + 问候 + 居中 composer）再跳回消息流。

「始终看到侧边栏」由导航壳挂在四个顶层页达成：合一页、历史、记忆中心、设置。**页内详情子页（某一天的记忆、某段会话、开发者诊断、隐私）不挂壳**——它们是叠在顶层页之上的一层，自带页内返回箭头即其导航出口；在顶层页上，返回交给侧边栏（窄屏交给抽屉）。

### 桌面（宽屏）

- 左侧常驻 **240px 毛玻璃侧边栏**：顶部品牌图标（点击回合一页）、三项导航（历史 / 记忆中心 / 设置）、底部连接状态。
- 连接状态：侧边栏**底部**一枚 6px 中性小圆点 + 一行 13px `muted` 文案「栖语在本机」；正常态不着紫、不用 `danger`（三色纪律）。仅 Host 健康探测失败时圆点与文案同时转 `danger` `#cc9999`，文案改为可点重试的措辞，点击重新探测。
- 连接状态还有**未探明**一态：首次探测结论回来之前，既不能宣称「在本机」、也不能报故障——那是把未知谎报成结论。此态保持中性呈现（不加第三种颜色、不加中间态视觉），只把措辞换成进行时的「正在确认本机连接」。
- 品牌图标：侧边栏/抽屉顶部保留「点击回合一页」的槽位，图形样式仍待设计，本轮以**中性几何占位**落地（不着紫、无渐变），不得沿用原型里的「紫色渐变圆 + 自造波纹」占位（与被弃的「波纹入皿」同源）。「回合一页」＝回到那个唯一的页面本身：本次会话已有消息时落回的仍是消息流，不借这个动作新建会话——那是行为改动，不属换皮范围。
- 无三条杠、无底部导航。

### 手机 / 窄屏

- 无常驻导航；左上角三条杠打开**抽屉**，宽度约视口 2/3，毛玻璃材质与桌面侧边栏同款；内含品牌图标、三项导航、连接状态。点遮罩或三条杠收回。
- 连接状态与桌面同款形态收进**抽屉底部**，不另设降级形态。

### 输入框（composer）位置

- **桌面两段式**：空状态居中（首页仪式感）；发出第一句后落底常驻。
- **手机**：全程底部常驻。

## 6. 首页背景图

使用用户指定的美术馆参考图（源图 `E:\Note\Asset\img\栖语\微信图片_20260825172300_5_1.jpg`，4096×3072、6.19MB）：

- 整体虚化（模糊 5px）；左右两侧深色渐变向中间过渡，**暗角要足**，整体偏暗（亮度 0.45、饱和度 0.55）。亮度与饱和度**合成一张 5×4 颜色矩阵**一次施加，不叠两层滤镜。
- 暗角由两层构成，都是规范定值：**左右深色渐变**（边缘一档、中间过渡一档，`stops 0 / 0.3 / 0.7 / 1`）+ **中心渐晕**（`RadialGradient` 由中心向外再压一档）。缺了渐晕，问候与输入框在图上立不住。
- 背景图存在时（空状态首页）必须铺成**全幅底层**，侧边栏与抽屉作为半透明层叠在它之上。若侧边栏与内容并排成两栏，夜景图会被 240px 栏整块切断。
- 口径限定：**要求全幅的是背景图，不是所有页面**。聊天态与历史 / 记忆中心 / 设置三页本就没有图可糊，侧边栏玻璃糊在纯色夜色底上是预期结果，不得按「玻璃底下必须有内容」返工，也不要求把内容列延伸到栏下做成真叠层。
- 图中暖黄灯光与紫夜色板的混色视为可接受，不强行统一色温；先实现后验收。
- 仅空状态出现；进入聊天状态后淡出，问候与背景**同一套时长语义**一起淡出，不留第二份可聚焦的问候。

入库资产工艺（定案）：

- 由 `scripts/prepare-visual-assets.ps1`（纯 PowerShell + System.Drawing，**不依赖 Node/npm**）一次性生成：等比缩到宽 1600、JPEG 质量 85，产物 `apps/qiyu_flutter/assets/images/home-night-backdrop.jpg`（实测 1600×1200、110KB）。质量 65 实测仅 66KB 且暗部细节明显发糊，故出图参数定在 85。
- 入库图保持原构图，虚化、暗角、亮度与饱和度**全部运行时施加**（blur 5 / brightness 0.45 / saturate 0.55 + 左右深色渐变），后续调参不必重新出图。
- 性能降级路径：若 CanvasKit 全屏 `ImageFiltered` 掉帧，改用预烘焙模糊图资产——属实现期决定，发生时须记录。

## 7. 消息区

- **单侧气泡**：用户消息右对齐**水滴气泡**（圆角 20/20/6/20，指向角柔和不尖锐，无描边，靠面色 `bubble-user` 与背景拉开层次）；栖语的话**无气泡**，宋体正文靠左、行高 1.9，书页式呈现。
- 旧规范的双侧气泡作废。

## 8. 组件清单与几何

几何 token：

- 圆角：`8px`（小元素）/ `18px`（卡片、列表项）/ 胶囊形（输入框）/ 圆形（图标按钮、发送钮）；气泡另定 20px 水滴形。方正小圆角（12px 及以下）已验证偏 AI 感，除小元素外不再使用。
- 间距：4px 基础网格，常用 8 / 12 / 16 / 24 / 32。

组件清单（全部 M3 底子 + token 换皮；页面只准消费这一层）：

1. **主按钮** — `accent-glass` 玻璃紫、`on-accent` 图标（确认、发送类）
2. **次按钮 / 文字按钮** — 无底色，`accent-bright` 文字
3. **圆形图标按钮** — 三条杠、语音、停止等
4. **发送按钮** — 圆形、**半透明玻璃紫**（`accent-glass` + 背景模糊 8px）、白色上箭头；**无描边、无白色高光**，只留极淡紫色光晕；生成中变停止钮
5. **输入框（composer）** — 毛玻璃、胶囊全圆角（`999px`）、`line` 发丝描边，占位字 `muted`，矮一档（内边距 6px）；占位字垂直居中（行高对齐按钮高度 34px）；聚焦态描边极克制的淡紫（透明度 0.13，只比无焦点略紫）
6. **导航项** — 图标 + 文字，选中态中性暗底 + 近白文字；圆角 **18px**（归组件 7 列表项同一档，不用 8，也不用原型的 12——12 及以下已验证偏 AI 感）
7. **列表项** — 历史 / 记忆条目，18px 圆角，悬停轻提亮
8. **卡片 / 面板** — `panel` 底 + `line` 发丝描边
9. **抽屉 / 侧边栏** — 毛玻璃，材质同源
10. **对话框 / 轻提示** — 直接用 M3 Dialog / SnackBar 换 token，不自造

补充约定：

- **选中态全站统一中性**（侧边栏导航、记忆中心 tab）：近白文字 + 中性暗底或淡白下划线，不用紫色。
- **记忆条目操作按钮常驻**（编辑 / 冻结 / 禁提 / 删除）：次要色、悬停提亮，不收入菜单——记忆控制权是产品的信任承诺，这条承诺兑现的是**操作入口常驻**（任何时刻点得到、不藏进菜单），**不是动作名的视觉可读性**。实现是无字图标 + tooltip + 读屏语义标签，动作名的可达性由三样共同承担：图标自身的形、读屏语义标签、长按/悬停提示。触屏上没有 hover，对有视力的触屏用户读动作名只剩长按一条——这条如实保留为**已知边界**，不写成已经解决（措辞边界见决策日志第五轮 #16）。第二条如实边界：§4 只定案五枚图形，**解冻与解除禁提沿用雪花 / 禁止圈的同一图形**，这两颗按钮的「图标自身的形」根本不区分动作，动作名只剩读屏标签与长按两条可走。
- 横向滚动容器不留滚动控件，界面里不出现浏览器/系统的横滚动条。当前发布形态里真实存在的只有一处：记忆中心四区 TabBar（`isScrollable`）。原先点名的另两处（记忆树、备份面板）实现期实测不成立——「关于你」是卡片堆叠、备份是对话框内的纵向滚动，两者都不是横滚容器；将来真出现横滚容器时同规矩套用。**这一条由框架档满足，应用层不写代码**：`MaterialScrollBehavior.buildScrollbar` 对 `Axis.horizontal` 直接返回 child，横滚本来就不画滚动条。**不要去包一层自定义 `ScrollConfiguration` 表示「我们去掉了它」**——挂基类 `ScrollBehavior` 会把该容器的越界回弹从 M3 的 stretch 换成基类 glow，换掉 `getPlatform` 的数据源，而可见结果一点没变；纵向滚动条不在这条要去之列。规范只锁结果：用例钉一个会画滚动条的平台档（`TargetPlatform.windows`），既断横滚容器里没有滚动条，也断同页纵向容器确实画出了滚动条——后半句是防止整条用例退化成空断言的正向对照。（点名校准、被推翻的做法与被拒项见决策日志第五轮 #14。）
- **设置页用阅读式**：分节不用卡片，小字距次要色标题 + 发丝分隔线；分节顺序固定：模型连接 → 语音朗读 → 语音转写 → 联网搜索 → 本地数据 → 隐私与边界 → 体验与开发者选项。
- **设置页分节可折叠**：点标题展开/收起，默认展开「模型连接」「本地数据」，其余收起；折叠状态本地持久化（仅 UI 状态，不进主持久化链路），上次收起来的下次进来还收着。不做吸顶子导航——分节标题本身就是导航，两排多余。

## 9. 无障碍与动效

- 键盘焦点：`2px solid accent-bright`，offset 3px。焦点环需**自绘**——Material 3 的 `focusColor` 只能贴在控件表面，画不出带 offset 的外环。
- **焦点表意按来源分开，两套不混用**：紫外环**只服务键盘焦点**，鼠标点击不得画出紫环；§8 组件 5 那条 0.13 淡紫描边**只服务输入框文本态**，与焦点环是两件事。
- **来源如何判定（定案）**：自己记录「最近一次改变焦点的输入来自键盘还是指针」，据此决定画不画环。**只读 `FocusManager.highlightMode` 不够**——桌面 Web 上它初始就是 `traditional`，而指针事件里的鼠标分支不改写模式，结果鼠标点中按钮照样画环；`highlightMode` 只在「键盘 ↔ 触摸」这类跨输入方式切换时才可靠。自实现守三条：判定以**焦点变更**为边界（无新焦点不改判）、**不下放**到各控件各自猜、触摸设备永不画环。
- 支持 `prefers-reduced-motion`：开启后关闭全部过渡与渐显——路由与页面转场、ink ripple（水波与高亮）、自绘的淡出与抽屉位移一律归零，不只是本段新增的那几条。
- **明确豁免**：进度指示器（如旋转的加载环）属「正在进行」这一状态的表意，关掉等于谎报状态，不在「关闭全部过渡」之列。
- 动效一律 150–250ms 轻缓动，时长收在 `QiyuMotion`（fast 160 / base 200 / drawer 220），不做视差、弹跳等花活。
- 深底上所有文字对比度留足余量。
