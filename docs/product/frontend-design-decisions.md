## 原型迭代定案（实现验收过的数值）

- 底色 `#15131A → #0f0e14`、面板 `#1e1b24 → #181719`、描边 `#353040 → #232227`、气泡 `#2b2733 → #252427`：表面全面中性化，去紫味。（此行为当时的原型迭代记录；气泡随后在第三轮定为 `#28272e`，以 §2 色板与第三轮第 7 条为准，原型的 `--bubble-user` 已同步。）

- 输入框：16px 圆角 → 胶囊全圆角，高度收矮（内边距 6px，按钮 34px）。
- 背景图：模糊 14px → 5px，亮度 0.45，饱和度 0.55。
- 选中态全站中性（侧边栏、tab），横向滚动容器隐藏原生滚动条。
- 认知突破：「紫色的房间」廉价，「紫夜」高级——紫只住强调色，由此形成三色纪律。
