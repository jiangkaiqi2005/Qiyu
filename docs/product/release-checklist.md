# 栖语 Web 产品发布前质量自检清单 (Release Quality Checklist)

为确保“栖语” Web 产品达到极高标准的发布级别 (SOTA Release Standards)，特制定本自检清单。

## 1. 自动化测试与质量指标 (Automated Checks)

- [x] **单元测试通过**: 执行 `npm test`，所有 78 个路由、模型、安全沙盒与组件渲染测试 100% 成功通过，未见任何断言失败或崩溃。
- [x] **黄金回归套件**: 执行 `npm run eval` 或通过 `/lab`（质量实验室）动态运行 9 个 golden cases 覆盖率回归，通过率达到 100%，所有语气、人格口癖与禁用语检测完全合规。
- [x] **无死链接**: 所有 SPA 页面（首页、对话、新手引导、设置中心、记忆中心、隐私政策、质量实验室）的跳转无死链接，刷新任一页面均能正确返回 index.html 且由路由自动接管分发。

## 2. 安全与隐私防护 (Security & Privacy Safeguards)

- [x] **API 密钥泄漏泄露防护**: 
  - API Key 存放在服务器配置文件或环境变量中，前端永远只与 `/api/chat` 做安全加密会话。
  - 设置中心及首次引导渲染已经保存的配置时，API Key 始终以掩码 `••••••••` 进行处理，且传输和显示都进行了掩码过滤，且绝不保存至 localStorage。
- [x] **静态资源审查**: 静态服务器具有坚固的安全过滤。隐藏的目录（如 `.git`、`.env`、`node_modules`）以及后台代码 and MD 配置文件（如 `栖语产品灵魂.md`）绝对被阻断读取，直接访问返回 `404 Not Found`。

## 3. 移动端与无障碍体验 (A11y & Mobile UX)

- [x] **多端自适应布局**: 
  - 在移动端（小于 768px）优雅降级为底部导航与状态条模式，对话区域维持焦点且有充足的软键盘弹出空间。
  - 在大屏端切换为精美双栏带左侧高级边栏结构。
- [x] **无障碍键盘焦点**: 全局开启 `:focus-visible` 耀眼金边焦点，对每个页面元素进行 tabindex 规范，首页顶部注入 `a.skip-link` 以便屏幕阅读器跳过全局边栏。
- [x] **动画衰减支持**: 尊重无障碍意图。若用户在操作系统开启“减弱动态效果” (prefers-reduced-motion)，CSS 规则将在一瞬间静默所有过渡、淡入和打字气泡跳动特效。

## 4. 离线 PWA 支持 (Progressive Web App)

- [x] **Web App Manifest**: manifest 配置完整，支持 standalone 运行模式与优雅的暗黑夜晚主题适配。
- [x] **离线缓存**: Service Worker 智能接管应用主外壳 (App Shell) 缓存，在断网时顺畅展示暖心中文离线 fallback 页面，同时绝对隔离 API 及敏感用户数据的离线缓存。

## 5. API 连接与诊断指标 (API Connection & Diagnostics)

- [x] **API 配置文件隔离**: 测试套件完全隔离，使用临时目录读写配置，确保本地真实配置文件不被覆盖或读取。
- [x] **终点地址规范化**: 用户填写的 Provider Base URL 自动且静默补全 `/chat/completions` 规范后缀。
- [x] **双阶段测试验证**: 
  - 设置页面及引导向导提供“测试 Provider 连接”（基础连通性握手）与“测试栖语回复”（栖语 Prompt 与人格回复 E2E 连通）的独立测试。
  - 错误脱敏校验：通信失败时，返回的错误信息中包含的敏感密钥信息 (长于3个字符) 均自动被过滤替换为 `[redacted]`。
- [x] **聊天链路可观察性**: 
  - 开启开发者模式下，`/chat` 对话页面的诊断区能实时打印每次交互的回复来源 (`llm` | `local`)、延迟 Ms 以及具体的降级原因（如敏感词、大模型异常、命中违禁词等）。
  - 连接状态动态持久化：一旦发生降级或测试成功，`localStorage` 中的 API 状态徽标与设置页运行仪表盘能同步刷新最新状况。

## 6. 首次运行与每日历史记录 (First Run & Daily History)

- [x] **首页分流与引导**: 首页根据 `onboardingState` 进行分流。未设置的首次用户将直接看到“开始设置”引导按钮，不显示试聊输入框。
- [x] **每日记录持久化**: 对话信息同步存储于 localStorage 中的 `dailyConversations` 结构。支持多天数据存储，且同天对话自动合并，新一天自动开启新会话。
- [x] **清空上下文非破坏性**: 聊天页“清空当前上下文”操作仅清空当前屏幕显示及 turns 上下文队列，绝对不会清空/删除 `dailyConversations` 中的归档记录。
- [x] **归档页面导航与交互**: 提供了专用的 `/history` 页面和“记录”图标链接，能够按日期倒序浏览。可点击特定日期查看当夜的全部对话气泡，并且支持二次确认删除指定日期记录。
- [x] **未配置 API 引导警告**: onboarding 步骤跳过 API 配置或连接测试失败时，在设置页顶部会渲染专属黄色警告 Banner 提醒用户去完成初遇引导配置。
