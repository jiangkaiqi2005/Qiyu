# 栖语语音只在完整交付后整段合成

只有当一条栖语回复通过全部安全校验、完整交付并落盘为 turn（`ChatDeliveryEvent` 的 `message` 事件）之后，才把最终文字整段送去 TTS 合成播放；不做 delta 流上的分句流式合成。原因：安全不变量要求用户绝不能看到未经完整校验的内容，而语音比文字更严苛——读出去的话收不回；流式分句会在终校完成前把半句播出去，一旦最终校验拦截或降级就无法撤回。栖语「默认少说」回复短，整段合成的首音延迟（约 1–2 秒）在睡前场景可接受。Host 中介与云端合成沿用 ADR 0001 的 STT 模式。

## Consequences

- TTS 是纯函数：turn 文字 → 音频，可随时重合成；音频内存即焚，不落盘、不进 sessions/记忆。
- 合成失败发生在文字交付之后，只降级不报错阻断：同一会话首次失败提示一次，后续静默跳过。
- 播放队列：新回复排队等上一段播完（不抢占，按序全播）；点麦克风立即停播并清空队列（防止转写录进栖语自己的声音形成自我循环）；停止按钮随时可停。
- 离开聊天页与导航换页一律**无条件停播**：页面卸载、点品牌槽回合一页、侧边栏或抽屉切换目的地，都要立刻停声、清掉排队中的气泡、作废在途合成——排队的朗读跨页继续读出去是不可接受的。这条语义在「紫夜」视觉换皮段一度被弱化成「只在正在朗读时才停」（为绕开框架锁定树阶段的崩溃），2026-08-30 恢复原语义：停播动作无条件执行，只把**通知**延到本帧之后——正在消失的监听者届时已解除订阅，还活着的监听者照常收到更新。
- 所有栖语 turn 一律朗读（含本地规则降级回复、安全回复、记忆召回的双 bubble），零例外。

## 安卓前台播放补充（2026-09-11）

按已批准的安卓版交互 Spec，安卓聊天朗读与设置试听只在前台播放。合成前通过现有播放平台取得临时音频焦点并监听输出设备变化；锁屏、后台、离页、焦点失败或丢失、耳机与蓝牙输出设备断开时，停止当前声音、清队并作废在途合成与播放器准备。焦点恢复、设备接回或页面恢复都不续播，用户主动重听或试听才开始新播放。

原生沿用 AudioManager 焦点、AudioDeviceCallback 与 ACTION_AUDIO_BECOMING_NOISY，不添加电话权限、后台服务或媒体控制。文字完整交付与落盘仍先于合成；音频只在内存，设置离页也释放试听结果。电脑 Web 的用户手势许可、音量、静音与 Esc 规则保留。
