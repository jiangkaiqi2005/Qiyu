# 栖语语音只在完整交付后整段合成

只有当一条栖语回复通过全部安全校验、完整交付并落盘为 turn（`ChatDeliveryEvent` 的 `message` 事件）之后，才把最终文字整段送去 TTS 合成播放；不做 delta 流上的分句流式合成。原因：安全不变量要求用户绝不能看到未经完整校验的内容，而语音比文字更严苛——读出去的话收不回；流式分句会在终校完成前把半句播出去，一旦最终校验拦截或降级就无法撤回。栖语「默认少说」回复短，整段合成的首音延迟（约 1–2 秒）在睡前场景可接受。Host 中介与云端合成沿用 ADR 0001 的 STT 模式。

## Consequences

- TTS 是纯函数：turn 文字 → 音频，可随时重合成；音频内存即焚，不落盘、不进 sessions/记忆。
- 合成失败发生在文字交付之后，只降级不报错阻断：同一会话首次失败提示一次，后续静默跳过。
- 播放队列：新回复排队等上一段播完（不抢占，按序全播）；点麦克风立即停播并清空队列（防止转写录进栖语自己的声音形成自我循环）；停止按钮随时可停。
- 所有栖语 turn 一律朗读（含本地规则降级回复、安全回复、记忆召回的双 bubble），零例外。
