# 全链路双语无缝切换与中文记忆本体架构

本 ADR 记录栖语全面支持英文版本（UI、提示词、本地规则、语音联动）及「侧边栏极简无缝切换」的架构决策：采用轻量纯 Dart 强类型词表实现界面瞬间热切，英文字体明确采用与思源宋体同宗同源的开源优雅西文衬线体 **Noto Serif / Source Serif**，模型提示词严格 1:1 忠实翻译，并在全链路切换语言时坚决守住「记忆不准变，该是中文就是中文」的不变量红线——底层 Markdown 记忆、画像与内部状态文件保持纯中文标准，跨语言交流由模型承担上下文理解与语义桥接。同时，严格限定前端改动范围：仅限在侧边栏/抽屉底部实现 demo 形式的 `中 / EN` 切换控件，不做任何多余的前端重构。

## Context & Decision

1. **界面层与英文字体：纯 Dart 词表 + 开源优雅衬线 Noto Serif / Source Serif。**
   - 英文字体定案为与思源宋体同宗同源的开源西文衬线体 **Noto Serif / Source Serif**（`fontFamily: 'Noto Serif', fontFamilyFallback: ['Noto Serif SC', 'Source Serif Pro', 'serif']`）：遵循 SIL Open Font License (OFL) 1.1 开源协议，与中文思源宋体的书卷感古典气质天然一致，字高（x-height）与基线原生对齐，零版权负担与零割裂感；
   - 界面词表采用轻量纯 Dart 强类型词表（`QiyuStrings` / `QiyuStringsZh` / `QiyuStringsEn`），零 `flutter_localizations` 与 `.arb` 外部生成依赖，编译期严格校验缺词漏词；
   - **前端改动范围铁律**：严格遵循 demo 交互，**只允许改前端侧边栏/抽屉底部的这一个 `中 / EN` 切换控件及其状态流转，绝对不改动前端其他多余的页面与组件**，防止范围蔓延。

2. **切换入口与交互：侧边栏/抽屉底部极简微型切换，无感热重绘。**
   完全遵照已验证的 Demo 交互形态落地：在桌面侧边栏底部 / 移动端抽屉底部的「连接状态（栖语在本机）」同栏紧凑排布微型双语切换项 `中 / EN`（遵守紫夜三色纪律：选中项为近白文本高亮，未选中项为 `muted` 暗灰色，hover 微亮）。点击立即原地生效：
   - 绝对不刷新页面、不重载路由、不丢弃输入框中未发送的草稿；
   - 历史聊天气泡保留当次对话发生时的原始语言（如实呈现客观历史，不做生硬机翻）；
   - 正在进行的流式输出或语音播放不被意外打断；
   - 下一轮发送的消息自动携带当前语言偏好，无缝切入对应语言回应。

3. **提示词体系：1:1 严格对照中文定稿，不增删设定。**
   英文版《Persona Constitution》、输出硬规则（Hard Rules）与隐藏块协议（Hidden Actions Protocol）严格 1:1 逐段逐句忠实翻译中文定稿，保持完全一致的精神内核与约束边界。隐藏块协议中的 JSON 动作键（`action`, `summary`, `evidence`, `keep`, `proactive` 等）与动作名称（`memory_signal`, `open_loop_candidate`, `deep_talk` 等）保持机器协议的强一致，不随自然语言变化。

4. **记忆本体红线：记忆不准变，该是中文就是中文。**
   栖语是睡前陪伴存在，人格、经历与关系阶段是唯一且连续的。底层 Markdown 记忆文件（`persona.md`, `relationship.md`, `open-loops.md`, episodes 日终/月压缩/Dream）与用户画像一律严格保持现行纯中文规范。模型在英文模式下对话时：
   - 历史中文记忆块（`<persona>`, `<daily_state>`, `<long_memory>`）原样注入模型上下文；
   - 模型在提示词引导下阅读中文记忆，用自然地道的英文与用户交谈；
   - 当用户用英文聊出新事实、新开环或记忆动作时，模型输出的隐藏块中的概括与状态（`summary` 等）按中文规范抽象提取落盘；
   - 彻底避免不同语言割裂记忆库，彻底避免不同语言导致底层解析器（Parser）与五段记忆节奏发生分支分叉。

5. **安全与本地兜底：英文正则扩展与 988 国际危机热线。**
   行为核心（`qiyu_behavior_core`）扩充英文高危词（`suicide`, `end my life`, `kill myself`, `exhausted` 等）的安全正则匹配。在未配置模型或降级兜底时：
   - 危机兜底在英文模式下提供国际通用的 988（Suicide & Crisis Lifeline）救助引导；
   - 医疗、法律、金融提供对应的英文免责与专业边界兜底；
   - 本地极简回复匹配英文输入（如 `I'm home` 兜底回 `Mmh.`, 疲惫输入兜底回 `What's up?`）。

6. **语音（STT/TTS）智能联动。**
   切换语言至英文时，TTS 预设音色在当前服务商下自动推荐匹配英文发音的音色（如 OpenAI 下自动切为 `nova`，豆包下切为支持双语/英文的音色），STT 录音转写切为英文或自动语种识别；同时尊重用户在设置页的手动覆盖。

7. **行为契约与自动化门禁。**
   在 `contracts/qiyu_behavior_contracts.json` 中补齐英文本地回复与安全事件的金样（Golden Cases），测试覆盖双语言下的一切边界行为，纳入 `verify-release-baseline.ps1` 强校验。

## Considered Options

- **英文字体使用商用闭源字体（如 Times New Roman）**：被拒。带有较重的办公工具感与商业版权约束，不如开源的人文主义衬线体纯粹。
- **英文字体使用现代无衬线（Roboto / Inter / System Sans）**：被拒。紫夜视觉规范的核心是「沉静书卷感与高级私密感」，无衬线字体会把产品退化为平庸的工业或效率工具。
- **全量重构前端各页面以全面适配多语言**：被拒。违反微创手术原则；用户明确要求只做侧边栏底部的这个 `中 / EN` 切换，以最小阻力接入，不改动其他多余前端。
- **分立独立的英文记忆空间（两套沙盒）**：被拒。关系阶段与经历会被清零，破坏栖语人格连续性的最高原则。
- **英文对话以英文落盘至 Markdown 记忆**：被拒。用户明确裁定“记忆不准变，该是中文就是中文”。混入英文会增加底层解析器、Dream 周期与月压缩的抽象复杂度，不如在 Prompt 层由大模型做语言桥接。
- **引入官方 flutter_localizations + intl + .arb 工具链**：被拒。栖语构建门禁要求纯 Dart/PowerShell、零外部冗余构建依赖；类型安全纯 Dart 词表方案编译期即可 100% 保证完整性，无需任何代码生成步骤。
- **整页刷新或重载会话以切换语言**：被拒。违背“无缝无感”要求，打断睡前陪伴的宁静沉浸感。

## Consequences

- 侧边栏/抽屉底部的连接状态行将挂载微型 `中 / EN` 切换控件，`EN` 文本显式指定 `Noto Serif` / `Source Serif` 字体族，与现有思源宋体资产天然融为一体。
- 前端发送 `/api/chat` 请求时携带 `locale` 字段，驱动 Host 端装配对应的英文提示词与选择对应的本地兜底话术。
- 大模型在英文模式下承担“阅读中文记忆 -> 英文自然对话 -> 提取中文规范记忆”的桥梁职责，需要在英文硬规则与提示词装配中明确注入该指令。
- 前端其余视图保持原样，不产生任何多余代码改动或侵入。
