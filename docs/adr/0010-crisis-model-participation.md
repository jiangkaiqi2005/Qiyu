# 危机输入处理反转：本地拦截改为模型参与＋降级兜底

2026-09-19 发布审计拷问裁定：原红线「危机/医疗/法律/金融等 non-normal 输入先在本地分类，绝不调用 Provider」反转——危机输入交给模型自己判断与回应。直接动机是审计发现本地危机正则可被字面变体（空格、拼音缩写、英文）绕过，变体堵不完；根本立场是相信现代模型对危机语言的判断力，与宪法「朋友发现你不对劲时认真说话」的定位一致。配套三件事：宪法新增「危险时刻」节（定稿文本如下，实现时原文照录）；本地热线固定话术保留为降级兜底（Provider 不可用、调用失败或未配置时顶上，保证无 Key 用户危机输入不掉到「嗯？」）；contracts 危机用例由 `providerCalls:0` 反转为模型参与，AGENTS.md 管线不变量同步改写。日终归档把危机轮（脱敏后）送 Provider 做记忆理解的口径随本裁定自然一致，不再是冲突项。

宪法「危险时刻」节定稿：

> 当用户的话语里出现伤害自己、结束生命这类信号，栖语先把它当成真的。她还是那个朋友：先认真接住对方此刻在说的话，把在意说出来，再温和地劝他联系身边能到场的人，自然地带上全国 24 小时心理援助热线 12356——像替朋友递一个电话号码那样递出去。她用平时说话的方式对待这件事：短句、平静、句句出自认真在听的人；要不要拨出去，由用户自己决定。

## Considered Options

- **维持拦截＋归一化修变体**：把闸门修厚（去空白/全半角/高危拼音缩写/英文关键词）。被否决：变体空间无限，闸门修不完；且模型被挡在危机对话之外，永远学不会产品想要的危机语气。
- **只做归一化、立场不动**：最小改动。被否决：绕过面依旧存在，只是变窄；立场问题没解决。
- **不拦截且不加宪法条文、不留兜底**：完全交给模型。被否决：宪法当时对危机零着墨，模型没有产品语气指引；无 Key 或故障时危机输入会掉到「嗯？」。

## Consequences

- 危机轮文本会实时外呼 Provider（脱敏照常），隐私口径从「危机轮零外呼」变为「危机轮参与模型对话」。
- 宪法仓库版与 Obsidian 笔记版（`栖语人格宪法.md`）需同步补「危险时刻」节。
- 契约 JSON 与行为核心测试的危机用例全部反转重写；「危机话术」golden 用例的语义改为「降级兜底路径」。
- 分类器保留，角色从闸门变为降级兜底的选择器（Provider 不可用/失败时按类别选本地话术）。
