# 记忆节奏独立成模块，聊天交付只留一个钩子

五段节奏中时间驱动各段（日终归档、月压缩、Dream）的调度与执行，连同启动恢复扫描与空闲补办，从聊天交付服务迁出，独立为「记忆节奏」模块：启动由组合根直接调用，每轮对话交付完成（轮内召回循环之后）由聊天服务只调一个钩子，动作在模块内部按固定先后串行执行。拒绝两个替代：把隐藏动作应用一并迁出——它消费本轮回复内容，属「应用本轮结果」的交付语义，迁出会把同轮原子性变成跨模块协调；维持现状内嵌——依赖面持续变宽，晚安/日终节奏没有独立测试入口，新记忆子系统都要穿构造参数。

## Consequences

- 聊天服务回到「安全交付一轮对话」单一职责，构造依赖收窄；节奏链失败仍只记本机诊断，页面通知是后续行为变更票（21）在新模块上的独立改动。
- 启动顺序约束（恢复扫描→补日终→补月压缩→补 Dream）收进模块内部，不再散在聊天服务里。
- 仓库说明的 Host 描述补「记忆节奏」一笔；回复管线不变量第 5 条是行为级表述，文字不动。
- 新记忆子系统接入只改「记忆节奏」一处，不再穿聊天服务构造参数。
